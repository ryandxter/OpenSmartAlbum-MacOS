## Tasks

### Task 1: Temporal Burst Clusterer (`src/domain/storytelling/temporalClusterer.ts`)
<task id="11-01-T1">
**Title:** Implement Chronological Burst Detection and Cluster Partitioning
**Target Files:**
- `src/domain/storytelling/temporalClusterer.ts`

**Details:**
1. Define `ClusterOptions`:
   - `maxPhotosPerSpread: number` (default: 6)
   - `minPhotosPerSpread: number` (default: 1)
   - `chapterGapSeconds: number` (default: 1800 / 30m)
   - `sceneGapSeconds: number` (default: 300 / 5m)
2. Define `PhotoCluster`:
   - `clusterIndex: number`
   - `photos: AdaptivePhoto[]`
   - `reason: 'chapter_break' | 'scene_break' | 'size_cap' | 'hero_moment'`
3. Implement `clusterPhotosChronologically(photos: AdaptivePhoto[], options?: Partial<ClusterOptions>): PhotoCluster[]`:
   - Sort photos chronologically using timestamp (`createdAt` or parsed timestamp), falling back to natural numeric sort on `fileName`.
   - Iterate adjacent pairs and calculate $\Delta t$.
   - Split at hard chapter gaps ($\Delta t \ge 1800\text{s}$).
   - Split large clusters ($> \text{maxPhotosPerSpread}$) at soft scene gaps ($\Delta t \ge 300\text{s}$) or balanced sub-splits.
   - Detect hero candidates (`isFavorite === true` or aspect $\ge 2.0$) and give them isolated clusters if requested.
   - Return array of `PhotoCluster` where every cluster satisfies $1 \le |C| \le 6$.
</task>

### Task 2: Narrative Cadence & Rhythm Engine (`src/domain/storytelling/cadenceEngine.ts`)
<task id="11-01-T2">
**Title:** Implement Visual Rhythm Scorer and Balanced Cadence Distributor
**Target Files:**
- `src/domain/storytelling/cadenceEngine.ts`

**Details:**
1. Implement cadence rhythm classification:
   - `archetype`: `'hero' (1) | 'duo' (2) | 'trio' (3) | 'quad' (4) | 'grid' (5-6)`
2. Implement `optimizeClusterCadence(clusters: PhotoCluster[]): PhotoCluster[]`:
   - Adjusts boundary photo between adjacent clusters to avoid monotone repetition (e.g. smoothing $[4, 4]$ into $[3, 5]$ or $[5, 3]$ if time gaps permit).
   - Ensures visual variety across sequential spreads.
</task>

---

### Task 3: Multi-Spread Auto-Flow Engine Facade (`src/domain/storytelling/autoFlowEngine.ts`)
<task id="11-01-T3">
**Title:** Orchestrate Multi-Spread Layout Partitioning and Variation Selection
**Target Files:**
- `src/domain/storytelling/autoFlowEngine.ts`

**Details:**
1. Define `AutoFlowSpreadPlan`:
   - `spreadIndex: number`
   - `clusterReason: string`
   - `photos: AdaptivePhoto[]`
   - `selectedVariation: AdaptiveLayoutVariation`
2. Implement `generateAutoFlowPlan(photos: AdaptivePhoto[], options: LayoutGeneratorOptions, clusterOpts?: Partial<ClusterOptions>): AutoFlowSpreadPlan[]`:
   - Calls `clusterPhotosChronologically`.
   - Calls `optimizeClusterCadence`.
   - For each cluster, calls `generateDynamicVariations` from `src/domain/layout/generator.ts`.
   - Selects the top-scoring variation with lowest aspect distortion.
   - Guarantees:
     - Total photos across all spreads equals `photos.length` (Zero-Loss).
     - Every slot has a valid photo (Zero-Blank).
</task>
