# Plan 12-02: Social Carousel Contextual Right-Click Studio Menu & Seamless Panorama Span Engine

**Plan ID:** 12-02
**Goal:** Implement a right-click studio context menu in Social Carousel mode, support multi-slide seamless panorama spanning (2 or 3 slides) with virtual split cut lines, and solve continuous seam alignment in the Phone Swipe Simulator.

## Tasks

### Task 1: Carousel Contextual Right-Click Studio Menu
<task id="12-02-T1">
**Title:** Implement Context Menu in `CarouselCanvas.tsx`
**Target Files:**
- `src/features/carousel/CarouselCanvas.tsx`
- `src/stores/carouselStore.ts`

**Details:**
1. In `src/features/carousel/CarouselCanvas.tsx`:
   - Add `contextMenu` state: `{ isOpen: boolean; x: number; y: number; frameId?: string | null; slideIndex?: number }`.
   - Attach `onContextMenu` to `CarouselFrameNode` and `Stage` background.
   - Render `<ContextMenu>` portal with studio actions:
     - `Set as Seamless Panorama Span (2 Slides)` (icon: `Maximize2` or `Columns`)
     - `Set as Seamless Panorama Span (3 Slides)` (icon: `Maximize2` or `Columns`)
     - `Set as Hero / Anchor Photo` (icon: `Star`)
     - `Reset Crop & Center` (icon: `RotateCcw`)
     - `Bring to Front` / `Send to Back`
     - `Delete Photo Frame` (danger)
2. In `src/stores/carouselStore.ts`:
   - Add `setPanoramaSpan: (slideIndex: number, frameId: string, spanSlides: 2 | 3) => void`.
     - Calculate target width: $\text{slideWidthPx} \times \text{spanSlides}$.
     - Ensure carousel has enough subsequent slides ($K + \text{spanSlides} \le \text{totalSlides}$). If not, automatically append required slides.
     - Reposition frame to align with left edge of slide $K$: $x = K \times \text{slideWidthPx}, y = 0, \text{height} = \text{slideHeightPx}$.
   - Add `setHeroPhotoOnSlide: (slideIndex: number, frameId: string) => void`.
     - Finds target photo.
     - Runs `generateDynamicVariations` with `heroPhotoId: targetFrame.photoId || targetFrame.id`.
     - Applies Variation 0 to active slide.
</task>

### Task 2: Seamless Panorama Intersection Projection in Phone Swipe Simulator
<task id="12-02-T2">
**Title:** Implement `getSlideIntersectingFrames` and Update `PhoneSwipeSimulator.tsx`
**Target Files:**
- `src/domain/carousel.ts`
- `src/features/carousel/PhoneSwipeSimulator.tsx`

**Details:**
1. In `src/domain/carousel.ts`:
   - Export `getSlideIntersectingFrames(allFrames: CarouselPhotoFrame[], slideIndex: number, slideWidth: number)`:
     - Detects frames whose $[x, x + w]$ bounding box overlaps slide $K$'s range $[K \cdot W, (K + 1) \cdot W]$.
     - Returns `{ frame, localX: frame.x - (slideIndex * slideWidth) }`.
2. In `src/features/carousel/PhoneSwipeSimulator.tsx`:
   - Instead of rendering only `slide.elements`, query all intersecting frames using `getSlideIntersectingFrames(allFrames, idx, slideW)`.
   - Calculate percentage offset: `left: ${(localX / slideW) * 100}%`, `width: ${(frame.width / slideW) * 100}%`.
   - Because each `.slideSurface` has `overflow: hidden`, Slide $K$ renders the left portion, and Slide $K+1$ renders the right portion with 100% continuous seam alignment during swipe transitions.
</task>

### Task 3: Virtual Split-Line Guides on Spanning Panoramas
<task id="12-02-T3">
**Title:** Visual Slice Guidelines for Multi-Slide Spanning Photos
**Target Files:**
- `src/features/carousel/CarouselCanvas.tsx`

**Details:**
1. In `CarouselCanvas.tsx`:
   - When a photo frame's width extends beyond 1 slide ($w > \text{slideWidthPx} + 1$):
     - In Layer 3 (Guides), render vertical dashed cut lines at each intermediate slide boundary crossing the photo:
       - Line at $X_{\text{cut}} = (K + 1) \cdot \text{slideWidthPx}$, color `#38bdf8`, dashed `[6, 4]`.
       - Small non-printing badge on top: `Slide K+1 Cut Line`.
</task>
