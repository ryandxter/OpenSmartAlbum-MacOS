## Context & Strategy
To deliver interactive divider dragging (DIV-01..03, DIV-05) and direct photo swapping (DIV-04) across both Print Album and Social Carousel modes, we need a pure mathematical domain engine that:
1. Analyzes an arbitrary set of rectangular photo frames ($F = \{f_1, f_2, \dots\}$) and extracts all internal shared boundaries (vertical and horizontal dividers).
2. Merges colinear segments into continuous through-dividers (e.g. $2 \times 2$ grid sharing a single vertical line) while preserving isolated T-junction dividers (e.g. horizontal shelf inside one column).
3. Computes exact closed-form delta bounds ($\Delta_{\min}, \Delta_{\max}$) enforcing both minimum dimensions ($W, H \ge 25.4\text{ mm}$ or $120\text{ px}$) and harmonic split ratios ($0.15 \le \alpha \le 0.85$), mathematically preventing layout collapse.
4. Identifies swap drop targets based on dragged frame center point containment.
5. Equips `carouselStore.ts` with `batchUpdateFrames` and `swapFrames` to match `editorStore.ts` for print albums.

## Tasks

<task id="13-01-01">
### Task 1: Implement `src/domain/layout/dividerGraph.ts`
Implement pure TypeScript algorithms:
- `extractCanvasDividers(frames: Array<{ id: string; x: number; y: number; width: number; height: number; rotation?: number; locked?: boolean }>, options?: { minDimension?: number; minOverlap?: number; maxGap?: number; minRatio?: number; maxRatio?: number }): CanvasDivider[]`
- Pairwise vertical adjacency detection ($x_B \ge x_A + w_A - \epsilon$, overlap on Y).
- Pairwise horizontal adjacency detection ($y_B \ge y_A + h_A - \epsilon$, overlap on X).
- Colinear segment merging: through-dividers vs T-junctions.
- Closed-form clamping computation for each divider: `minCoord` and `maxCoord` based on $S_{\min}$ and $\alpha \in [0.15, 0.85]$.
- `findPhotoSwapTarget(elements, point, excludeFrameId)`: Detects if a coordinate point $(x, y)$ falls within any valid photo frame on the canvas.
</task>

<task id="13-01-02">
### Task 2: Add `batchUpdateFrames` and `swapFrames` in `src/stores/carouselStore.ts`
