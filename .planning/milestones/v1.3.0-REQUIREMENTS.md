# Requirements: OpenSmartAlbum-MacOS (Milestone v1.3.0)

**Defined:** 2026-09-28  
**Completed:** 2026-09-29  
**Core Value:** Solid workspace mode isolation, complete SQLite and package persistence for Social Carousel, resilient multi-photo drag-and-drop, and Figma-grade polygon corner radius fillets.

---

## v1.3.0 Requirements Summary

### Carousel Canvas Drag-and-Drop & Filmstrip UX (CAR)

- [x] **CAR-01**: User can drag multiple selected photos (or batch handle) from Filmstrip onto `CarouselCanvas` (`.stageWrapper`) and have them reliably placed on the target slide without canvas blanking or WebKit drag cancellation.
  - *Outcome:* Validated. Listener bound to `.stageWrapper`, frame placement stable across 1-10+ photos.
- [x] **CAR-02**: Drag ghost badge (`#afsn-drag-ghost-badge`) is positioned within visible bounds with non-interfering opacity (`opacity: 0.01`, `pointer-events: none`), preventing macOS WebKit drag session cancellations.
  - *Outcome:* Validated. DOM-attached badge prevents WebKit drag aborts.
- [x] **CAR-03**: Dropping $N$ photos onto a slide batches frame creation into a single state update with a single atomic undo/redo history entry.
  - *Outcome:* Validated. Atomic history transaction committed; `Cmd+Z` reverts full batch drop.
- [x] **CAR-04**: Filmstrip context menu (`PhotoContextMenu`) and double-click actions detect `activeMode`, routing photo placement to the active slide in Carousel mode and to the active spread in Print Album mode.
  - *Outcome:* Validated. Context menu labels and actions dynamically route based on `activeMode`.

### Social Carousel Persistence & Database Storage (PERS)

- [x] **PERS-01**: SQLite schema introduces tables/columns for carousel projects, persisting slides, photo frames, aspect ratios, slide order, and background colors.
  - *Outcome:* Validated. `migrate_v16` applied; unit tests pass in `test_migrate_v16_and_schema_version`.
- [x] **PERS-02**: Project save (`Cmd+S`, menu item, and autosave) saves both Print Album and Carousel state seamlessly without data loss.
  - *Outcome:* Validated. Bi-directional IPC save/load verified with full project round-trip tests.
- [x] **PERS-03**: Reopening an `.afsn` project or SQLite database fully restores all carousel slides, frame geometries, and customizations.
  - *Outcome:* Validated. Verified in `test_carousel_package_export_import_and_bundled_zip`.
- [x] **PERS-04**: Carousel store tracks `isDirty` state, displaying correct save indicator status in the title bar and warning on unsaved window close.
  - *Outcome:* Validated. Amber/green save status indicator on title bar; native window close sheet prevents accidental exits.

### Workspace Isolation & Mode State Synchronization (ISO)

- [x] **ISO-01**: Elevate `activeMode` (`'print' | 'carousel'`) to global `appStore` with auto-detection on project open based on canvas unit (`px` vs `mm/in`).
  - *Outcome:* Validated. Hoisted to `appStore`; auto-detects unit on load.
- [x] **ISO-02**: Viewport zoom and pan state are cleanly isolated (`printZoom` vs `carouselZoom`), preventing accidental scale jumps when switching modes.
  - *Outcome:* Validated. Zoom levels preserved independently.
- [x] **ISO-03**: Title bar controls (Undo/Redo, "Add Text", Export) and keyboard shortcuts dispatch strictly to the active mode's store.
  - *Outcome:* Validated. Action dispatches guarded by `activeMode`.
- [x] **ISO-04**: Reordering, deleting, or duplicating slides in `carouselStore` automatically recalculates and shifts contained frames' absolute `x` coordinates, preventing frame detachment.
  - *Outcome:* Validated. Slide `x` coordinate shifts keep frames attached to slides.
- [x] **ISO-05**: Dynamic layout cycling and auto-flow in Carousel mode preserve frame border styling and shape masks instead of stripping them.
  - *Outcome:* Validated. Layout cycling preserves custom frame borders, radii, and shapes.

### Vector Shape Mask Corner Radii & Polygon Tangent Fillets (VEC)

- [x] **VEC-01**: Inspector's `ShapesBordersSection` displays Corner Radius slider and individual corner inputs for all polygon shapes (Hexagon, Octagon, Star, Scallop, Heart), removing the artificial rectangle-only restriction.
  - *Outcome:* Validated. Unlocked corner radius controls in Inspector.
- [x] **VEC-02**: Implement mathematical vertex tangent fillet arc algorithm (`c.arcTo` in Canvas 2D and quadratic bezier/arc in SVG) in `src/domain/shapes.ts` to smoothly round polygon and star vertices.
  - *Outcome:* Validated. Mathematical tangent fillet arcs with dynamic self-intersection clamp; 10/10 test suites passed.
- [x] **VEC-03**: Custom SVG shape upload normalizes viewBox dimensions and handles multi-path clipping groups properly.
  - *Outcome:* Validated. `normalizeCustomSvgMask` merges all SVG primitives with aspect-fit containment; Rust export parity in `psd_writer.rs`.
- [x] **VEC-04**: Oval shape preset is added to the UI button presets in `ShapesBordersSection.tsx` with full contour and crop support.
  - *Outcome:* Validated. Dedicated Oval button in preset grid; 1:1 contour border and crop verified.
