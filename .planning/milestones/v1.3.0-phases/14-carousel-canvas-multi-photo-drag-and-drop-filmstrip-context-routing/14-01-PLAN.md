## Context & Strategy
In macOS WKWebView (Tauri runtime), dragging photo items from the Filmstrip Tray or Batch Action Bar onto the Carousel Canvas frequently produces blank canvases or fails to initiate drops for two architectural reasons:
1. Intermediate DOM elements (`div.stageWrapper`) intercept pointer hit-testing without calling `e.preventDefault()`, causing WebKit's native drag controller to abort drops before reaching the canvas container.
2. Drag ghost badges (`#afsn-drag-ghost-badge`) positioned offscreen at `-1000px, -1000px` have their render layers culled by WebKit's compositor, triggering immediate drag session cancellation (`NSDragOperationNone`).
3. Dropping onto off-center slides leaves the active slide outside the viewport without a smooth transition.

This plan resolves these interaction failures by:
- Relocating HTML5 drag listeners (`onDragOver`, `onDragLeave`, `onDrop`) directly to `.stageWrapper` in `CarouselCanvas.tsx`, invoking `e.preventDefault()` and `e.stopPropagation()`, setting `e.dataTransfer.dropEffect = 'copy'`, and guarding against child element drag-leave flicker.
- Re-architecting `#afsn-drag-ghost-badge` DOM positioning in `FilmstripTray.tsx` and `BatchActionBar.tsx` to remain within visible viewport bounds (`top: 0, left: 0`) snapshotted at `opacity: 1`, then transitioned via RAF to `opacity: 0.01; pointer-events: none;` without WebKit layer culling.
- Implementing a cancelable 60fps RAF smooth panning helper (`smoothPanToSlide`) with `easeOutCubic` curve and auto-centering on drop completion.

### Task 1: Add HTML5 Drag Listeners to `.stageWrapper` in `CarouselCanvas.tsx`
**Target File:** `src/features/carousel/CarouselCanvas.tsx`

1. **Attach Handlers to `.stageWrapper`:**
   - Move `onDragOver`, `onDragLeave`, and `onDrop` from `.canvasContainer` directly to `div.stageWrapper` (lines 853–878).
   - In `handleDragOver`:
     - Invoke `e.preventDefault()` and `e.stopPropagation()`.
     - Explicitly set `e.dataTransfer.dropEffect = 'copy'` on every tick.
     - Calculate target slide and hit frame, setting `hoveredDropSlideIndex` and `hoveredDropReplaceFrameId`.
   - In `handleDragLeave`:
     - Add flicker prevention guard:
       ```typescript
       if (e.currentTarget.contains(e.relatedTarget as Node)) return;
       setHoveredDropSlideIndex(null);
       setHoveredDropReplaceFrameId(null);
       ```
   - In `handleDrop`:
     - Invoke `e.preventDefault()` and `e.stopPropagation()`.
     - Read bounding box directly from `stageWrapper` or stage container for pixel-perfect continuous coordinate translation:
       ```typescript
       const box = e.currentTarget.getBoundingClientRect();
       const canvasX = (e.clientX - box.left - stagePos.x) / scale;
       const canvasY = (e.clientY - box.top - stagePos.y) / scale;
       ```
     - Remove duplicate drop handlers from `.canvasContainer` so event interception is single-point and unambiguous.
2. **Visual Replacement Ring Feedback:**
   - In the Konva rendering loop of `CarouselCanvas.tsx`, when `hoveredDropReplaceFrameId === frame.id`, render a glowing cyan dashed indicator ring (`stroke: '#38bdf8'`, `dash: [6, 4]`, `strokeWidth: 2`) signaling in-place photo replacement.

<task id="14-01-03">
### Task 3: Cancelable 60fps RAF Smooth Panning `smoothPanToSlide` in `CarouselCanvas.tsx`
**Target File:** `src/features/carousel/CarouselCanvas.tsx`

1. **Implement `smoothPanToSlide`:**
   - Define cancelable RAF animation hook/ref `panAnimationRef = useRef<number | null>(null)`.
   - Calculate exact horizontal and vertical centering coordinates:
     $$X_{target} = \text{round}\left(\frac{W_c}{2} - \left(X_s + \frac{W_s}{2}\right) \cdot S\right)$$
     $$Y_{target} = \text{round}\left(\frac{H_c}{2} - \frac{H_s}{2} \cdot S\right)$$
     where $W_c, H_c$ are container dimensions, $X_s = \text{slideIndex} \cdot W_s$, and $S = \text{zoomLevel} / 100$.
   - Animate stage position using an `easeOutCubic` timing curve over 280ms:
     `ease = 1 - Math.pow(1 - progress, 3)`.
2. **Wire Drop Completion & Gesture Interruption:**
   - At the conclusion of `handleDrop`, invoke `setActiveSlide(targetSlideIdx)` and `smoothPanToSlide(targetSlideIdx, 280, true)` unconditionally, guaranteeing the slide centers smoothly even if `targetSlideIdx === activeSlideIndex`.
   - In user-initiated viewport gestures (`onMouseDown`, `handleWheel`, `fitToScreen`), immediately call `cancelSmoothPan()` to prevent animation fighting or stutter.
   - Clean up `panAnimationRef` in the `useEffect` unmount handler.
</task>
