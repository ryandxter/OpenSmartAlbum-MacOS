- **Plan:** 15-01

- **Requirements Covered:** `PERS-01`, `PERS-03`
- **Status:** Completed

---

## Context & Strategy
Currently, OpenSmartAlbum-MacOS persists Print Album projects into SQLite tables (`album_spreads`, `spread_elements`) and `.afsn` packages. However, Social Carousel projects exist exclusively in volatile frontend RAM (`useCarouselStore`), with zero schema support in SQLite or `.afsn`. Quitting the app or reloading causes total data loss.

This plan establishes the foundation for complete Social Carousel persistence:
1. Implement transaction-safe schema migration `migrate_v16` in `src-tauri/src/db/mod.rs`, introducing `projects.project_type`, `carousels`, `carousel_slides`, and `carousel_frames` with cascading foreign keys (`ON DELETE CASCADE`).
2. Add relational data payloads (`CarouselPayload`, `CarouselSlidePayload`, `CarouselFramePayload`) and implement atomic transactional `save_carousel_structure` and `load_carousel_structure` methods in `Database`.
3. Expose IPC commands in `project_commands.rs`, register them in `lib.rs`, and extend `ProjectPackagePayload` in `package_io.rs` with `pub carousel: Option<CarouselPayload>` to guarantee bidirectional `.afsn` archive export/import and bundled photo ZIP archiving for carousel frames.

2. **Implement `Database::save_carousel_structure` & `Database::load_carousel_structure`:**
   - In `Database::save_carousel_structure(&self, carousel: &CarouselPayload) -> SqliteResult<()>`:
     - Open transaction.
     - Upsert into `carousels` table.
     - Delete existing `carousel_slides WHERE project_id = ?1` (which cascades to `carousel_frames`).
     - Insert slides into `carousel_slides`.
     - For each frame, verify photo existence in `photos` table to prevent dangling references; then insert into `carousel_frames`.
     - Update project `updated_at = datetime('now')`.
     - Commit transaction.
   - In `Database::load_carousel_structure(&self, project_id: &str) -> SqliteResult<Option<CarouselPayload>>`:
     - Query `carousels WHERE project_id = ?1`. If not found, return `Ok(None)` cleanly.
     - Query `carousel_slides WHERE project_id = ?1 ORDER BY slide_index ASC`.
     - For each slide, query `carousel_frames WHERE slide_id = ?1 ORDER BY z_index ASC, rowid ASC`.
     - Return `Ok(Some(carousel))`.
3. **Add IPC Commands in `src-tauri/src/commands/project_commands.rs`:**
   ```rust
   #[tauri::command]
   pub fn save_carousel_structure(
       db: State<'_, Database>,
       carousel: CarouselPayload,
   ) -> Result<(), String> {
       log::info!("save_carousel_structure for project: {}", carousel.project_id);
       db.save_carousel_structure(&carousel).map_err(|e| e.to_string())
   }

   #[tauri::command]
   pub fn load_carousel_structure(
       db: State<'_, Database>,
       project_id: String,
   ) -> Result<Option<CarouselPayload>, String> {
       log::info!("load_carousel_structure for project: {}", project_id);
       db.load_carousel_structure(&project_id).map_err(|e| e.to_string())
   }
   ```
4. **Register in `src-tauri/src/lib.rs`:**
   - Add `commands::project_commands::save_carousel_structure` and `commands::project_commands::load_carousel_structure` to `tauri::generate_handler![...]`.
</task>
