## Context & Strategy
In macOS applications, terminating the window (`Cmd+W`), clicking the red window traffic light, or quitting (`Cmd+Q`) with unsaved edits must present a non-destructive confirmation dialog per Apple Human Interface Guidelines.
Currently, `src/App.tsx` lines 151–175 only check `useAlbumStore.getState().saveStatus`. When a user modifies a Social Carousel project, `is_unsaved` in Rust `AppExitState` remains `false`. Tauri's `WindowEvent::CloseRequested` handler in `src-tauri/src/lib.rs` lets the window close immediately, obliterating unsaved carousel work.

This plan addresses this critical vulnerability and implements cover slide thumbnail caching:
1. Re-wire `syncUnsavedStatus` in `src/App.tsx` to subscribe to both `useAlbumStore` and `useCarouselStore`, synchronizing `is_unsaved` to native Rust `AppExitState`.
2. Ensure `ExitWarningModal.tsx` handles Carousel projects cleanly on "Save & Exit", "Exit Without Saving", and "Cancel".
3. Implement cover slide (slide 0) PNG thumbnail rendering and disk caching on save for high-performance preview in `WelcomeScreen.tsx` Recent Projects browser.
4. Build comprehensive automated test suites across Rust and TypeScript.

1. **Rust Thumbnail Storage Command:**
   - In `src-tauri/src/commands/project_commands.rs`, implement:
     ```rust
     #[tauri::command]
     pub fn save_project_thumbnail(
         app: tauri::AppHandle,
         project_id: String,
         base64_png: String,
     ) -> Result<String, String> {
         let app_cache_dir = app.path().app_cache_dir().map_err(|e| e.to_string())?;
         let thumb_dir = app_cache_dir.join("project_thumbnails");
         std::fs::create_dir_all(&thumb_dir).map_err(|e| e.to_string())?;
         let file_path = thumb_dir.join(format!("{}.png", project_id));
         
         let data = base64_png
             .strip_prefix("data:image/png;base64,")
             .unwrap_or(&base64_png);
         let bytes = base64::engine::general_purpose::STANDARD
             .decode(data)
             .map_err(|e| e.to_string())?;
         std::fs::write(&file_path, bytes).map_err(|e| e.to_string())?;
         Ok(file_path.to_string_lossy().to_string())
     }
     ```
