# Plan 01-02: macOS Font Scanner, Text Rasterizer Fallback & Pure-Rust Test Suite

## Metadata
- **Phase:** 01 — macOS Foundation & Pure Rust Pipeline
- **Plan ID:** 01-02
- **Requirements:** PLAT-01, PLAT-02
- **Goal:** Implement native macOS system font discovery with `ttf-parser`, add resilient bundled font (`inter`) fallback in the text rasterizer to guarantee flawless text rendering, purge all obsolete `libvips` references across the codebase, and verify 100% test success across the pure-Rust test suite on macOS Darwin.
- **Dependencies:** 01-01 (Tauri 2 macOS Configuration & Win32 FFI Elimination)

---

## Context & Strategy

In the current codebase:
1. `get_system_fonts` on macOS returns an empty vector `Ok(Vec::new())` because it previously only enumerated the Windows Registry. This prevents the typography dropdown from listing installed fonts on macOS.
2. The text rasterizer's font loader (`load_font_weight`) returns `None` if a requested system font cannot be located in the Windows font directory. When running on macOS, tests requesting Windows fonts like "Century Gothic" (e.g. `test_user_rotated_scenario`) fail because text is silently dropped rather than falling back to bundled high-quality fonts.
3. Multiple files across UI, backend, and documentation incorrectly reference `libvips`, even though the backend already uses a 100% pure Rust stack (`image 0.25`, `rayon 1.10`, `fontdue 0.9`, `kamadak-exif 0.6`).

This plan resolves these issues:
- Add `ttf-parser = "0.25"` directly to `Cargo.toml`.
- Implement macOS font discovery in `src-tauri/src/commands/app_commands.rs` across `/System/Library/Fonts`, `/Library/Fonts`, and `~/Library/Fonts`, parsing `.ttf`, `.otf`, and TrueType collections (`.ttc`) via `ttf_parser`.
- Add an automatic fallback to bundled `"inter"` in `text_rasterizer.rs:load_font_weight()`.
- Cleanly purge all `libvips` mentions across UI strings, configuration, and documentation.
- Verify full test suite passes with `cargo test --manifest-path src-tauri/Cargo.toml` (37/37 tests passing).

### Task 1: macOS System Font Directory Discovery with ttf-parser

- **Files:**
  - `src-tauri/Cargo.toml`
  - `src-tauri/src/commands/app_commands.rs`

- **Action:**
  1. In `src-tauri/Cargo.toml`:
     - Add `ttf-parser = "0.25"` under `[dependencies]` (this crate is already compiled as an indirect dependency of `fontdue`).
  2. In `src-tauri/src/commands/app_commands.rs`:
     - Implement Darwin font scanning in `get_system_fonts()` under `#[cfg(target_os = "macos")]`.
     - Scan font directories:
       - `/System/Library/Fonts`
       - `/Library/Fonts`
       - `~/Library/Fonts` (if `HOME` env var is set)
     - Iterate through files with extensions `.ttf`, `.otf`, and `.ttc`:
       - Read file bytes and determine font count using `ttf_parser::fonts_in_collection(&data).unwrap_or(1)`.
       - Parse each face using `ttf_parser::Face::parse(&data, index)`.
       - Extract Family Name (Name ID 1, preferring English/Unicode names) and Full Name (Name ID 4).
       - Skip empty or inaccessible font faces.
     - Deduplicate fonts using lowercased family names to avoid duplicate family entries.
     - Sort alphabetically by `family` name.
     - Keep Windows Registry scanning under `#[cfg(target_os = "windows")]`.
  3. In `src-tauri/src/commands/app_commands.rs:tests`:
     - Update `test_get_system_fonts_smoke`:
       - Add Darwin assertions under `#[cfg(target_os = "macos")]`:
         ```rust
         #[cfg(target_os = "macos")]
         {
             assert!(!fonts.is_empty(), "Should find fonts on macOS system");
             assert!(
                 fonts.iter().any(|f| {
                     let fam = f.family.to_lowercase();
                     fam.contains("arial") || fam.contains("helvetica") || fam.contains("times") || fam.contains("sf")
                 }),
                 "Should include common macOS system fonts (Helvetica, Arial, SF, or Times)"
             );
         }
         ```

- **Verification:**
  - `cargo test --manifest-path src-tauri/Cargo.toml commands::app_commands::tests::test_get_system_fonts_smoke`
  - Verify test passes and returns macOS system font list.

- **Acceptance Criteria:**
  - `get_system_fonts()` returns non-empty list of fonts on macOS.
  - Common macOS fonts (e.g. Helvetica, Arial, Times) are present in the returned list.
  - `test_get_system_fonts_smoke` passes on Darwin.
</task>
