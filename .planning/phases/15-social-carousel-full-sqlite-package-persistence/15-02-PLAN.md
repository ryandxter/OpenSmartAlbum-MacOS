## Context & Strategy
Once the Rust backend persistence layer is available, the frontend must integrate with it seamlessly:
1. `useCarouselStore` needs state tracking (`saveStatus`, `lastSavedAt`), a dirty marking mechanism (`markDirty()`), and persistence actions (`saveCarouselToDb()`, `loadCarouselFromDb()`).
2. `useProjectStore` currently routes all save and open actions exclusively through `useAlbumStore`, which breaks when managing carousel projects. It must inspect project mode (`canvasUnit === 'px'` or `projectType === 'carousel'`) and branch appropriately for `saveProject`, `openProjectById`, `openProjectFromFile`, `importProjectFromAfsn`, and `createNewProject`.
3. `src/features/persistence/useAutoSave.ts` must track carousel state, maintain local storage crash snapshot recovery (`afsn_carousel_snapshot_${id}`), debounce autosaves at 2.5s, save immediately on window `blur`, and drive the amber/green status pill in `AppTitleBar.tsx`.

### Task 1: Add Persistence State & Actions to `src/stores/carouselStore.ts`
**Target File:** `src/stores/carouselStore.ts`

1. **Extend `CarouselState` Interface:**
   ```typescript
   export interface CarouselState {
     // ... existing fields ...
     saveStatus: 'saved' | 'saving' | 'unsaved';
     lastSavedAt: string | null;

     // Persistence Actions
     markDirty: () => void;
     setSaveStatus: (status: 'saved' | 'saving' | 'unsaved') => void;
     saveCarouselToDb: () => Promise<boolean>;
     loadCarouselFromDb: (projectId: string) => Promise<boolean>;
   }
   ```
2. **Implement Persistence Logic in `useCarouselStore`:**
   - Default state: `saveStatus: 'saved'`, `lastSavedAt: null`.
   - `markDirty`:
     ```typescript
     markDirty: () => {
       if (get().saveStatus !== 'unsaved') {
         set({ saveStatus: 'unsaved' });
       }
     },
     ```
   - `setSaveStatus`:
     ```typescript
     setSaveStatus: (status) => {
       const updates: Partial<CarouselState> = { saveStatus: status };
       if (status === 'saved') {
         updates.lastSavedAt = new Date().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
       }
       set(updates);
     },
     ```
   - `saveCarouselToDb`:
     - Checks `currentCarousel`.
     - Invokes Tauri command `'save_carousel_structure'` passing `{ carousel: currentCarousel }`.
     - On success: updates `lastSavedAt`, clears dirty state in localStorage (`afsn_dirty_${projectId}`), returns `true`.
     - On failure: sets `saveStatus: 'unsaved'`, logs error, returns `false`.
     - Supports fallback if running in web/non-Tauri mode.
   - `loadCarouselFromDb`:
     - Invokes Tauri command `'load_carousel_structure'` passing `{ projectId }`.
     - If result is `null` or undefined, returns `false`.
     - If result is a valid `CarouselPayload`, constructs domain `Carousel` model, sets `currentCarousel`, resets `past: []`, `future: []`, `canUndo: false`, `canRedo: false`, sets `saveStatus: 'saved'`, and returns `true`.
3. **Instrument Carousel Mutations with `markDirty()`:**
   - Ensure every mutation in `carouselStore.ts` calls `get().markDirty()`:
     - `setRatio`, `addSlide`, `duplicateSlide`, `deleteSlide`, `reorderSlide`, `updateSlideBackground`.
     - `addPhotoFrame`, `addPhotoFrames`, `updatePhotoFrame`, `removePhotoFrame`.
     - `applyCarouselLayout`, `cycleSlideLayout`, `applyDynamicSlideLayoutByIndex`, `shuffleSlidePhotos`, `autoFlowPhotosToSlides`.
     - `setPanoramaSpan`, `setHeroPhotoOnSlide`, `batchUpdateFrames`, `swapFrames`.
   - Undo and redo actions should also set `saveStatus: 'unsaved'`.
</task>

### Task 2: Update `src/stores/projectStore.ts` for Mode-Aware Persistence & Hydration
**Target File:** `src/stores/projectStore.ts`

1. **Mode Detection Helper:**
   - A project is a carousel project if `project.canvasUnit === 'px' || project.projectType === 'carousel'`.
2. **Update `saveProject(options)`:**
   - Detect `isCarousel`:
     - If `isCarousel`:
       - Obtain `useCarouselStore.getState()`.
       - Verify `currentCarousel && currentCarousel.projectId === current.id`.
       - Set `useCarouselStore.getState().setSaveStatus('saving')`.
       - Persist margins and spacing if applicable.
       - Await `useCarouselStore.getState().saveCarouselToDb()`.
       - If working `.afsn` path exists: invoke `'export_afsn_package'`, handling file existence checks and `export_afsn_with_dialog` fallback for deleted files.
       - Set `useCarouselStore.getState().setSaveStatus('saved')`.
       - Return `{ success: true, filePath: workingPath, isSaveAs: false }`.
     - If Print Album: continue with existing `useAlbumStore` pipeline.
3. **Update `openProjectById(id)`:**
   - When project is loaded:
     - If `isCarousel`:
       - Call `const loaded = await useCarouselStore.getState().loadCarouselFromDb(project.id);`.
       - If `!loaded`: call `useCarouselStore.getState().initializeCarousel(project.id)`.
       - If project has `.afsn` file path, verify file exists on disk.
       - Set `useCarouselStore.getState().setSaveStatus(hasUnsavedRecovery || !hasProjectFile ? 'unsaved' : 'saved')`.
     - If Print: maintain existing `useAlbumStore.getState().loadAlbumFromDb(project.id)`.
4. **Update `createNewProject(settings)`:**
   - When `settings.unit === 'px'`, set `projectType: 'carousel'` in project record.
   - Initialize carousel in `useCarouselStore` with `settings.carouselRatio`.
   - Immediately await `useCarouselStore.getState().saveCarouselToDb()` so the initial template is immediately written to SQLite with `saveStatus = 'saved'`.
5. **Update `openProjectFromFile(filePath)` and `importProjectFromAfsn()`:**
   - After invoking `import_project_package` or `import_afsn_package`, inspect imported project `canvasUnit` / `projectType`.
   - If carousel, hydrate `useCarouselStore` by calling `loadCarouselFromDb(imported.id)`.
</task>

### Task 3: Overhaul `useAutoSave.ts` and Titlebar Indicator
**Target Files:**
- `src/features/persistence/useAutoSave.ts`
- `src/features/workspace/AppTitleBar.tsx`

1. **Update `src/features/persistence/useAutoSave.ts`:**
   - Subscribe dynamically to both `useAlbumStore` and `useCarouselStore`.
   - Determine `isCarousel = currentProject?.canvasUnit === 'px' || (currentProject as any)?.projectType === 'carousel'`.
   - Determine active `saveStatus = isCarousel ? carouselSaveStatus : albumSaveStatus`.
   - **LocalStorage Crash Snapshot Recovery:**
     - For carousel projects, serialize `currentCarousel` to `localStorage.setItem('afsn_carousel_snapshot_' + currentProject.id, ...)`.
   - **Dirty Flag Synchronization:**
     - Update `localStorage.setItem('afsn_dirty_' + currentProject.id, '1')` when `saveStatus === 'unsaved'`, and remove when `'saved'`.
   - **Debounced Autosave (2.5 seconds):**
     - When `saveStatus === 'unsaved'`, set a 2.5s timer (`autoSaveIntervalSeconds = 2.5`) calling `useProjectStore.getState().saveProject({ automatic: true })`.
   - **Immediate Save on Window Blur:**
     - Add `window.addEventListener('blur', handleBlur)`:
       ```typescript
       const handleBlur = () => {
         const isDirty = isCarousel
           ? useCarouselStore.getState().saveStatus === 'unsaved'
           : useAlbumStore.getState().saveStatus === 'unsaved';
         if (isDirty) {
           void useProjectStore.getState().saveProject({ automatic: true });
         }
       };
       ```
2. **Update `src/features/workspace/AppTitleBar.tsx`:**
   - Read `saveStatus` and `lastSavedAt` from active mode store (`carouselStore` vs `albumStore`).
   - Titlebar status pill:
     - When `saveStatus === 'unsaved'`: render glowing amber dot (`#F59E0B`, `styles.statusDotUnsaved`), tooltip `"Unsaved changes (⌘S to save)"`.
     - When `saveStatus === 'saving'`: render pulsing indicator with `"Saving changes..."`.
     - When `saveStatus === 'saved'`: render green dot (`#10B981`) with `"All changes saved"`, displaying `lastSavedAt` when available.
</task>
