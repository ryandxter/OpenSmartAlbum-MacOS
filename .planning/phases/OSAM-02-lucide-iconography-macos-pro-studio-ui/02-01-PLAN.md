## Context & Strategy

OpenSmartAlbum currently contains over 180 raw inline `<svg>` elements and unicode emojis (`💾`, `📂`, `🖼️`, `⚙️`, `🔒`, `✂️`, `🔍`, `📐`, `✏️`, `✕`) scattered across 22 components. These lack standardized stroke weights, sizes, and color inheritance. Furthermore, `--color-accent: #38bdf8` (sky blue) emits a saturated blue cast around the canvas periphery, visually distorting white-balance judgment when photographers proof and color-grade album spreads.

This plan executes the visual foundation of Phase 2:
1. **Dependency**: Install `lucide-react` into `package.json`.
2. **Design Tokens (`src/styles/tokens.css`)**:
   - Deep neutral charcoal canvas & surface palette (`#18181B` Zinc-900 base, `#1E1E22` secondary, `#27272A` tertiary, `#2D2D32` surface, `#2E2E33` border).
   - **Neutral Monochrome / Graphite accent** (`#E4E4E7` primary foreground accent, `rgba(255, 255, 255, 0.08)` subtle, `rgba(255, 255, 255, 0.18)` border) eliminating color cast.
   - Apple SF Pro font stack (`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "SF Pro", "Helvetica Neue", sans-serif`).
   - Icon sizing tokens (`--icon-size-micro: 14px`, `--icon-size-compact: 16px`, `--icon-size-standard: 20px`, `--icon-size-featured: 24px`) and stroke weights (`--icon-stroke-default: 1.5`, `--icon-stroke-micro: 1.75`).
3. **Icon Migration**: Replace all inline SVGs and emojis across:
   - UI Core: `Dialog.tsx`, `ConfirmDialog.tsx`, `ColorPicker.tsx`
   - Editor HUDs & Panels: `FrameToolbar.tsx`, `TypographyPanel.tsx`, `LockedPhotosPanel.tsx`, `LayoutCycleHUD.tsx`
   - Media & Spreads: `FilmstripTray.tsx`, `FolderTabs.tsx`, `PageNavigator.tsx`, `TemplatesPanel.tsx`
   - Modals & Workspace: `NewProjectDialog.tsx`, `WelcomeScreen.tsx`, `AboutDialog.tsx`, `SettingsDialog.tsx`, `ExportAlbumDialog.tsx`, `ExportProgressModal.tsx`
