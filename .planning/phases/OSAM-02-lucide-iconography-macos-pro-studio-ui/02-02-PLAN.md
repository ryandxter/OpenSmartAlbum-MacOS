## Context & Strategy

In traditional desktop ports, window headers often render below a generic OS window bar or feature non-native window controls. On macOS, professional studio applications (such as Figma, Adobe Lightroom, and Final Cut Pro) integrate the titlebar directly into the application canvas:
1. Native macOS traffic light buttons (close, minimize, zoom) sit inside the application header at the top-left.
2. The header provides an 80px left padding (`pl-20`) so traffic lights never overlap menu items.
3. The background functions as a window drag region (`data-tauri-drag-region`), allowing photographers to position the window naturally while child buttons explicitly disable dragging (`-webkit-app-region: no-drag`) to prevent click swallowing.
4. The center displays the active project title with an unsaved indicator (`•` amber dot).
5. The right section hosts the **Mode Switcher button shell** (`Print Album` ↔ `Social Carousel`, paving the way for Phase 3 `CARO-01`), along with primary action buttons (Export, Settings, Properties).

Currently, `src/features/workspace/WorkspaceLayout.tsx` has ~450 lines of topbar code using emojis and mixed drag/drop logic. We will extract this into an isolated, performant `AppTitleBar.tsx` component.

### Task 2: Build `AppTitleBar` Component with 80px Inset, Drag Regions & Mode Switcher Shell

- **Files:**
  - `src/features/workspace/AppTitleBar.tsx` (new file)
  - `src/features/workspace/AppTitleBar.module.css` (new file)

- **Action:**
  1. Create `src/features/workspace/AppTitleBar.module.css`:
     - Set container height to `var(--toolbar-height, 44px)`.
     - Set `display: flex; align-items: center; justify-content: space-between;`.
     - Background: `var(--color-bg-secondary, #1e1e22)` with bottom border `1px solid var(--color-border, #2e2e33)`.
     - Traffic light left padding: on macOS (or by default in CSS), `padding-left: var(--mac-traffic-light-inset, 80px)`.
     - Set `user-select: none;`.
     - Set non-interactive background areas to `cursor: default;`.
     - For all interactive children (buttons, menus, inputs, segmented controls):
       ```css
       -webkit-app-region: no-drag;
       app-region: no-drag;
       ```
     - Define styles for:
       - Menu buttons (`File`, `Help`) with subtle hover states.
       - Centered project title: font weight 600, SF Pro typography, editable on double-click/pencil click, uncommitted change indicator dot (`•` in amber `#f59e0b`).
       - Mode Switcher segmented pill:
         - Shell container with background `var(--color-bg-tertiary, #27272a)`, border radius `6px`, padding `2px`.
         - Two segments: `Print Album` (active default, icon `BookOpen`) and `Social Carousel` (icon `Layers` or `Instagram` styled, with badge "Beta" or "Phase 3").
       - Right action buttons: Save, Package, Add Text, Export, Settings, Properties panel toggle.
  2. Create `src/features/workspace/AppTitleBar.tsx`:
     - Container receives `data-tauri-drag-region`.
     - Left column:
       - Traffic light spacer (`80px`).
       - `File` dropdown menu (New Project, Open, Save, Save As, Export AFSN, Import AFSN, Close Project) with Lucide icons (`FolderOpen`, `Save`, `Download`, `Package`, `X`).
       - `Help` dropdown menu (About, Shortcuts, Check for Updates) with Lucide icons (`Info`, `Keyboard`, `Sparkles`).
       - History buttons: `Undo2` (`⌘Z`), `Redo2` (`⌘⇧Z`).
     - Center column:
       - Has `data-tauri-drag-region` on wrapper.
       - Renders project name with rename input support on double click.
       - Renders save indicator dot (`•` amber when `saveStatus === 'unsaved'`, green when saved).
     - Right column:
       - **Mode Switcher Shell**:
         ```tsx
         <div className={styles.modeSwitcher} role="group" aria-label="Editor Mode">
           <button
             type="button"
             className={`${styles.modeBtn} ${activeMode === 'print' ? styles.modeActive : ''}`}
             onClick={() => setActiveMode('print')}
           >
             <BookOpen size={14} strokeWidth={1.5} />
             <span>Print Album</span>
           </button>
           <button
             type="button"
             className={`${styles.modeBtn} ${activeMode === 'carousel' ? styles.modeActive : ''}`}

               onModeSelect?.('carousel');

             title="Instagram Carousel Mode (Coming in Phase 3)"
           >
             <Layers size={14} strokeWidth={1.5} />
             <span>Social Carousel</span>
             <span className={styles.modeBadge}>Soon</span>
           </button>
         </div>
         ```
       - Quick Action buttons:
         - Add Text (`Type`)
         - Export (`Download`)
         - Settings (`Settings`)
         - Properties Inspector Toggle (`PanelRight` / `PanelRightClose`)
     - Wire up all callbacks to existing Zustand stores (`useProjectStore`, `useAlbumStore`, `useAppStore`, `useHistoryStore`, `useEditorStore`).
