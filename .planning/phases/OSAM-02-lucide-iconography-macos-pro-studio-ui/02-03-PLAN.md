# Plan 02-03: Modular 4-Section Multi-Expandable Inspector Panel & Bottom Status Bar

## Metadata
- **Phase:** 02 — Lucide Iconography & macOS Pro Studio UI
- **Plan ID:** 02-03
- **Requirements:** UIUX-03, UIUX-05
- **Goal:** Extract the 2,300-line monolithic inspector in `WorkspaceLayout.tsx` into an isolated, modular 4-section multi-expandable accordion system (`src/features/inspector/`: Layout & Spacing, Shapes & Borders, Typography, Effects & Shadows) with persistent section state, and implement a macOS Pro Studio Bottom Status Bar (`src/features/workspace/StatusBar.tsx`) with canvas DPI/dimension readout, snapping toggles, and live zoom slider.
- **Dependencies:** 02-01, 02-02 complete

---

## Context & Strategy

Currently, `src/features/workspace/WorkspaceLayout.tsx` is an unwieldy 3,535-line monolith. Over 2,300 lines are dedicated to deeply nested inline inspector controls with tangled ternary operators for single frames, multi-selections, and canvas spread dimensions. Furthermore, there is no bottom status bar (`UIUX-05`) for live spread dimensions, DPI readout, or quick snapping toggles.

This plan executes a clean architectural decomposition:
1. **Modular Multi-Expandable Inspector (`src/features/inspector/`)**:
   - `AccordionSection.tsx`: Clean, accessible expandable accordion card with animated Lucide chevrons (`ChevronDown`) and CSS-grid transition (`grid-template-rows: 0fr` -> `1fr`).
   - `useAccordionState.ts`: Multi-expandable state manager with `localStorage` persistence, allowing photographers to keep Spacing, Borders, and Shadows open simultaneously.
   - 4 Dedicated Sections:
     - `LayoutSpacingSection.tsx`: X, Y, Width, Height, Aspect Ratio lock, Rotation, Align/Distribute buttons, Gap slider, and Spread Canvas dimensions when no element is selected.
     - `ShapesBordersSection.tsx`: Corner radii (4-corner unlinked + master slider), Border stroke width/color/style, and Shape preset selector shell (for Phase 4).
     - `TypographySection.tsx`: Font family selector, size slider, alignment, line-height, letter-spacing, and styled text range editor.
     - `EffectsShadowsSection.tsx`: Opacity slider with % badge, Drop shadow toggle, blur, offset X/Y, and shadow color.
   - `InspectorContainer.tsx`: Host container with tabs for Properties, Smart Layout (`TemplatesPanel`), and Locks (`LockedPhotosPanel`).
2. **Bottom Status Bar (`src/features/workspace/StatusBar.tsx`)**:
   - Fixed height (`28px`), border-top `1px solid var(--color-border)`.
   - Left: Active spread dimensions and unit readout (`16.0 × 8.0 in @ 300 DPI`), active spread page count / number label.
   - Center: Snapping toggle indicator (`Snap: ON / OFF`), guide visibility indicators (Gutter, Bleed, Safe Area).
   - Right: Interactive zoom slider with numerical percentage badge and `Fit` button.
3. **WorkspaceLayout Refactoring**:
   - Replace 2,300+ lines of inline inspector markup with `<InspectorContainer />`.
   - Render `<StatusBar />` along the bottom workspace edge.

## Tasks

<task id="02-03-T1">
### Task 1: Build Accordion Section & State Hook (`src/features/inspector/`)

- **Files:**
  - `src/features/inspector/useAccordionState.ts` (new file)
  - `src/features/inspector/AccordionSection.tsx` (new file)
  - `src/features/inspector/AccordionSection.module.css` (new file)

- **Action:**
  1. Create `src/features/inspector/useAccordionState.ts`:
     - Provide a hook `useAccordionState(defaultOpenSections: string[])`:
       - Reads initially open sections from `localStorage.getItem('open_inspector_sections')` or defaults to `['layout', 'shapes', 'typography', 'effects']`.
       - Returns `{ openSections, toggleSection, isOpen, expandAll, collapseAll }`.
       - Persists changes back to `localStorage` on change.
  2. Create `src/features/inspector/AccordionSection.module.css`:
     - Header: `display: flex; align-items: center; justify-content: space-between; padding: 8px 12px; cursor: pointer; background: var(--color-bg-secondary); border-bottom: 1px solid var(--color-border-subtle);`.
     - Title area: `display: flex; align-items: center; gap: 8px; font-size: var(--font-size-sm, 12px); font-weight: 600; color: var(--color-text-primary);`.
     - Chevron indicator: `transition: transform 180ms cubic-bezier(0.4, 0, 0.2, 1);` rotated 180deg when open.
     - Body wrapper: CSS grid animation technique:
       ```css
       .contentGrid {
         display: grid;
         grid-template-rows: 0fr;
         transition: grid-template-rows 200ms ease-out;
       }
       .contentGridOpen {
         grid-template-rows: 1fr;
       }
       .innerContent {
         overflow: hidden;
         padding: 0;
       }
       .innerContentOpen {
         padding: 12px;
       }
       ```
  3. Create `src/features/inspector/AccordionSection.tsx`:
     - Props: `id: string`, `title: string`, `icon: LucideIcon`, `isOpen: boolean`, `onToggle: () => void`, `badge?: ReactNode`, `children: ReactNode`.
     - Uses `ChevronDown` from `lucide-react` (`size={14}`, `strokeWidth={1.5}`).

- **Verification:**
  - Compile with `npx tsc --noEmit`.

- **Acceptance Criteria:**
  - Accordion section expands and collapses smoothly using CSS grid height technique.
  - Multi-expandable state correctly toggles individual sections without closing others.
</task>

<task id="02-03-T2">
### Task 2: Implement the 4 Inspector Sections & InspectorContainer

- **Files:**
  - `src/features/inspector/sections/LayoutSpacingSection.tsx` (new file)
  - `src/features/inspector/sections/ShapesBordersSection.tsx` (new file)
  - `src/features/inspector/sections/TypographySection.tsx` (new file)
  - `src/features/inspector/sections/EffectsShadowsSection.tsx` (new file)
  - `src/features/inspector/InspectorContainer.tsx` (new file)
  - `src/features/inspector/InspectorContainer.module.css` (new file)

- **Action:**
  1. Create `LayoutSpacingSection.tsx`:
     - Supports three operational modes based on editor selection:
       - **Single Frame Selected**: X, Y, Width, Height inputs, Aspect Ratio lock toggle (`Ratio`), Rotation angle input + 90° CCW/CW quick buttons (`RotateCcw`, `RotateCw`), Reset Crop button.
       - **Multi-Selection Active**: Batch Alignment buttons (`AlignLeft`, `AlignCenter`, `AlignRight`, `AlignTop`, `AlignMiddle`, `AlignBottom`), Distribute Spacing buttons (`DistributeHorizontal`, `DistributeVertical`), Dynamic Gap slider and input with dynamic unit limits.
       - **Canvas Spread Selected (No Selection)**: Spread Dimensions (Page Width, Page Height, Unit selector: inches, mm, cm, px), Spread DPI, Spine Gutter width, Bleed margin, Safe Area margin inputs, and "Apply to All Spreads" action buttons.
  2. Create `ShapesBordersSection.tsx`:
     - Corner Radius: master slider and unlinked 4-corner inputs (TL, TR, BR, BL) using `getCornerRadii`.
     - Border & Stroke: Toggle switch for border enabled, Stroke color picker using `ColorPicker`, Stroke width numeric slider/input, Stroke style selector (Solid, Dashed).
     - Shape Preset Shell (preparing for Phase 4 `SHAPE-01`): Preset buttons for Rectangle, Rounded Rect, Circle/Oval.
  3. Create `TypographySection.tsx`:
     - Embeds font selector (system fonts and curated album fonts), font size slider, weight toggles (Bold, Normal), alignment buttons (`AlignLeft`, `AlignCenter`, `AlignRight`), line-height, letter-spacing, and styled text range editor when a `TextNodeElement` is selected.
     - When no text is selected, displays clean placeholder hint or quick "Add Text Box" button.
  4. Create `EffectsShadowsSection.tsx`:
     - Opacity slider (0% to 100%) with numeric percentage readout using `objectOpacity` domain model.
     - Drop Shadow controls: Drop shadow enabled toggle switch, Shadow Color swatch (`ColorPicker`), Blur radius slider (0-50px), Offset X & Offset Y sliders (-30px to +30px).
     - Reset effects action button.
  5. Create `InspectorContainer.tsx` and `InspectorContainer.module.css`:
     - Hosts the 3 top tabs:
       - **Properties** (`SlidersHorizontal` icon)
       - **Smart Layout** (`LayoutGrid` / `Wand2` icon) -> renders `<TemplatesPanel />`
       - **Locks** (`Lock` icon with count badge) -> renders `<LockedPhotosPanel />`
     - Collapse button on top right (`PanelRightClose` or `ChevronRight`).
     - When in "Properties" tab, renders the 4 accordion sections:
       `<AccordionSection id="layout" title="Layout & Spacing" icon={SlidersHorizontal} ...>`
       `<AccordionSection id="shapes" title="Shapes & Borders" icon={Square} ...>`
       `<AccordionSection id="typography" title="Typography" icon={Type} ...>`
       `<AccordionSection id="effects" title="Effects & Shadows" icon={Sparkles} ...>`

- **Verification:**
  - `npx tsc --noEmit` validates all components and props without errors.

- **Acceptance Criteria:**
  - Inspector contains all 4 modular sections with clean typography and Lucide icons.
  - All input changes correctly trigger existing `editorStore` and `albumStore` actions.
</task>
