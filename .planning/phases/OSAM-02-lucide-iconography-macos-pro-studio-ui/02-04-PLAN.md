## Context & Strategy

Photographers on macOS expect fluent desktop ergonomics:
1. **Apple Shortcut Glyphs**: Rather than Windows-style `"Ctrl+Z"` or `"Ctrl+S"`, tooltips and shortcut sheets on macOS must display Apple glyphs: `⌘Z`, `⌘⇧Z`, `⌘S`, `⌘E`, `⌘0`, `⌥`, and `⌫`. Keydown listeners must consistently treat `e.metaKey` as the primary command modifier.
2. **Fluid Trackpad Gestures**: In macOS WKWebView, trackpad pinch-to-zoom emits `wheel` events with `e.ctrlKey === true` and fine continuous `deltaY` values. Snapping these to rigid 5% steps creates jarring, jerky zooming. We replace this with smooth exponential focal-point scaling. Furthermore, two-finger panning (`e.deltaX`, `e.deltaY`) must glide smoothly across the stage viewport.
3. **Pro Studio Polish**: Ensure all panels, borders, status bars, and modal surfaces maintain zero chromatic cast (pure neutral graphite accents `#E4E4E7` and Zinc-900 `#18181B`) so color-grading album spreads remains completely true to life.
4. **Validation**: Run the full 17-suite test harness (`npm test`) and TypeScript verification.

       export interface ShortcutDefinition {
         ctrlOrCmd?: boolean;
         altOrOption?: boolean;
         shift?: boolean;
         key: string;
       }

       export function formatShortcut(shortcut: ShortcutDefinition): string {
         const mac = isMac();
         const parts: string[] = [];
         if (shortcut.ctrlOrCmd) parts.push(mac ? '⌘' : 'Ctrl+');
         if (shortcut.altOrOption) parts.push(mac ? '⌥' : 'Alt+');
         if (shortcut.shift) parts.push(mac ? '⇧' : 'Shift+');
         parts.push(mac ? shortcut.key.toUpperCase() : shortcut.key.toUpperCase());
         return parts.join(mac ? '' : '');
       }

       export const SHORTCUTS = {
         UNDO: { ctrlOrCmd: true, key: 'Z' },
         REDO: { ctrlOrCmd: true, shift: true, key: 'Z' },
         SAVE: { ctrlOrCmd: true, key: 'S' },
         EXPORT: { ctrlOrCmd: true, key: 'E' },
         ZOOM_IN: { ctrlOrCmd: true, key: '+' },
         ZOOM_OUT: { ctrlOrCmd: true, key: '-' },
         ZOOM_FIT: { ctrlOrCmd: true, key: '0' },
         ADD_TEXT: { key: 'T' },
         PROPERTIES: { key: 'P' },
         LOCKS: { key: 'L' },
         SMART_LAYOUT: { key: 'G' },
         DELETE: { key: 'Backspace' },
       };
