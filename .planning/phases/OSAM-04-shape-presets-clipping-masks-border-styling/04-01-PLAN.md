## Overview

Implement the vector shape clipping generator in `src/domain/shapes.ts`, extend `PhotoFrameElement` in `src/domain/editor.ts`, and integrate shape clipping into `KonvaEditorCanvas.tsx` (`PhotoFrameNode`) and `CarouselCanvas.tsx`.

---

## Tasks

1. **Create `src/domain/shapes.ts`**:
   - `ShapeType`: `'rectangle' | 'rounded' | 'circle' | 'oval' | 'hexagon' | 'octagon' | 'star' | 'scallop' | 'heart' | 'custom_svg'`
   - Preset path generators:
     - `createPolygonPath(sides, w, h)`
     - `createStarPath(points, w, h, innerRadiusRatio)`
     - `createHeartPath(w, h)`
     - `createScallopPath(w, h, count)`
   - SVG path normalizer: scale any standard SVG `d` path string to fit $[0, w] \times [0, h]$.
   - `renderShapePath(ctx: CanvasRenderingContext2D, shapeType: ShapeType, w: number, h: number, radii?: [number, number, number, number], customSvg?: string): void`

2. **Extend `PhotoFrameElement` in `src/domain/editor.ts`**:
   - Add `shapeType?: ShapeType;`
   - Add `customSvgPath?: string;`

3. **Integrate clipping in `KonvaEditorCanvas.tsx` (`PhotoFrameNode`)**:
   - In `PhotoFrameNode`, use `clipFunc: (ctx) => renderShapePath(ctx._context, frame.shapeType || 'rectangle', frame.width * scaleFactor, frame.height * scaleFactor, ...)`
   - Or render `<Path />` / `<Shape />` with corresponding SVG path string.
   - Ensure `calculateMultiFrameResize` continues to preserve topological gaps between shape frames.

4. **Add Unit Tests in `tests/shapes.test.ts`**:
   - Verify polygon, star, heart, and scallop path math.
   - Verify topological resize compatibility.

5. **Commit Plan 04-01**:
   - `git add -A && git commit -m "feat(shapes): implement vector shape clipping engine and Konva integration (Plan 04-01)"`
