# Plan 18-01: Core Rich Text Domain Helpers & Selection Formatting Engine

## 1. Goal & Scope
Implement the core mathematical and domain primitives for direct-canvas rich text editing:
- `#RGB` / `#RRGGBB` Hex normalization with deferred 3-digit expansion to eliminate mid-typing color flashes.
- Active selection format extractor (`getActiveSelectionFormat`) with multi-color and mixed-style detection.
- Styled range coalescing & normalization (`normalizeStyledRanges`) to prevent range fragmentation during continuous color scrubbing.
- Background highlight application and 1-click transparent clear (`applyHighlightToRange`).
- Dual-engine data model alignment: extend `CarouselTextFrame` in `src/domain/carousel.ts` and `carouselStore.ts` with `styledRanges` and `style` overrides for 100% data model parity between Print Album and Social Carousel.

### 2.1 `src/domain/richTextSelection.ts` (NEW)
```typescript
import { TextStyle, StyledRange } from './text';

export interface ActiveSelectionFormat {
  isSelectionActive: boolean;
  isCollapsed: boolean;
  // Color & Highlight
  fill: string | 'MIXED';
  isFillMixed: boolean;
  highlight: string | 'MIXED' | 'NONE';
  isHighlightMixed: boolean;
  // Font & Style
  isBold: boolean | 'MIXED';
  isItalic: boolean | 'MIXED';
  isUnderline: boolean | 'MIXED';
  fontFamily: string | 'MIXED';
  fontSize: number | 'MIXED';
  align: 'left' | 'center' | 'right' | 'justify';
}

/**
 * Normalizes input string to uppercase #RRGGBB or returns null if invalid.
 * If allowThreeDigitExpand is true, expands 3-digit hex (#RGB -> #RRGGBB).
 * If false, only accepts 6-digit hex (used during active typing to prevent flashing).
 */
export function normalizeHexColor(input: string, allowThreeDigitExpand: boolean = true): string | null;

/**
 * Extracts unified formatting state across an active text selection slice [start, end].
 * Detects mixed states when selection spans multiple distinct formats.
 */
export function getActiveSelectionFormat(
  text: string,
  baseStyle: TextStyle,
  ranges: StyledRange[] | undefined,
  selection: { start: number; end: number } | null
): ActiveSelectionFormat;

/**
 * Coalesces adjacent ranges with identical formatting properties and removes collapsed ranges.
 */
export function normalizeStyledRanges(ranges: StyledRange[] | undefined): StyledRange[];

/**
 * Applies or clears text background highlight across a character range.
 */
export function applyHighlightToRange(
  ranges: StyledRange[] | undefined,
  start: number,
  end: number,
  highlightColor: string | undefined
): StyledRange[];
```

## 3. TDD Test Plan (`src/domain/__tests__/styledRangesFormatting.test.ts`)

Create comprehensive Vitest test suite testing all edge cases:

1. **Hex Normalization Tests:**
   - `#F00` with `allowThreeDigitExpand=true` -> `#FF0000`.
   - `#F00` with `allowThreeDigitExpand=false` -> `null` (buffers without premature lime-green jump).
   - `#0052B4`, `0052b4`, `#1E293B` -> correctly capitalized 6-digit hex `#0052B4`, `#1E293B`.
   - Invalid strings (`#12345`, `xyz`, `#1234567`) -> `null`.
   - Empty or whitespace strings -> `null`.

2. **Active Selection Format Extraction Tests:**
   - Collapsed selection (`start === end`): returns base style and `isCollapsed: true`.
   - Uniform selection across single range: returns exact range style (e.g. `isBold: true`, `fill: '#FF0000'`).
   - Mixed text colors: selection covering word A (`#FF0000`) and word B (`#0052B4`) -> `isFillMixed: true`, `fill: 'MIXED'`.
   - Mixed highlights: selection covering highlighted word (`#FEF08A`) and unhighlighted text -> `isHighlightMixed: true`, `highlight: 'MIXED'`.
   - Mixed formatting: selection covering bold and normal text -> `isBold: 'MIXED'`.
   - Out-of-bounds selection clamps safely without throwing errors.

3. **Range Coalescing & Fragmentation Tests (`normalizeStyledRanges`):**
   - Merges contiguous adjacent ranges with identical properties `[0, 5]` and `[5, 10]` into `[0, 10]`.
   - Removes empty/collapsed ranges where `start >= end`.
   - Keeps distinct adjacent ranges `[0, 5]` (bold) and `[5, 10]` (italic) intact.

4. **Background Highlight Application & 1-Click Clear:**
   - Setting highlight `#FEF08A` applies `highlight: '#FEF08A'` to selected slice.
   - Setting highlight `undefined` cleanly removes `highlight` property, reverting to transparent.

5. **Dual-Engine Model Compatibility:**
   - `CarouselTextFrame` accepts `styledRanges` and converts seamlessly to `TextRun[]` using `rangesToTextRuns`.
