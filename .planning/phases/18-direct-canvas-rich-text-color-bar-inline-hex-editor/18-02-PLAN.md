# Plan 18-02: Docked TextFormatToolbar Component, Hex Popovers & Inspector Sync

## 1. Goal & Scope
Build the modular, Figma-grade direct-canvas formatting toolbar component (`TextFormatToolbar.tsx`) and synchronize rich text highlight controls with `TypographyPanel.tsx`:
- Mac Dark Studio UI (`#18181b` surface, `#27272a` border, SF Pro typography, Lucide icons).
- Bold, Italic, Underline toggles with active/mixed visual indicators.
- Text Color Picker:
  - Solid swatch or conic-gradient for `Mixed`.
  - Visible Hex input field (`#RRGGBB` or placeholder `"Mixed"`).
  - Popover color picker (2D saturation/brightness box, hue slider, color presets, and eyedropper).
  - Non-blurring input mechanics: typing does not dismiss active contentEditable selection.
- Text Background Highlight Picker:
  - Swatch preview with color/none/mixed indication.
  - Visible Hex input field (`#RRGGBB` or empty).
  - 1-Click "Clear / Transparent" button (`Ban` / `Slash` icon).
  - Highlighter preset palette (Yellow, Green, Blue, Pink, Orange, Lavender, Slate Dark, Neutral Gray, White Glow).
- Font size stepper `[-] [ 24 pt ] [+]` and direct numerical input.
- Text alignment toggles (Left, Center, Right, Justify).
- Synchronize `TypographyPanel.tsx` in the Inspector to also support text background highlights with 1-click clear, ensuring 100% bidirectional parity between direct canvas and inspector panels.

## 2. Target Files & Architecture

### 2.1 `src/features/editor/TextFormatToolbar.tsx` (NEW)
```typescript
import React from 'react';
import { ActiveSelectionFormat } from '../../domain/richTextSelection';
import { StyledRange } from '../../domain/styledRanges';
import { TextStyle } from '../../domain/text';

export interface TextFormatToolbarProps {
  activeFormat: ActiveSelectionFormat;
  onApplyRangeFormat: (patch: Partial<Omit<StyledRange, 'id' | 'start' | 'end'>>) => void;
  onApplyBaseStyle: (patch: Partial<TextStyle>) => void;
  onClearHighlight: () => void;
  onStartSamplingColor?: () => void;
  isSamplingColor?: boolean;
  disabled?: boolean;
  style?: React.CSSProperties;
  className?: string;
}
```

#### Key Functional Rules & Zero-Blur Architecture:
1. **Zero-Blur Button Protection:**
   - Every `<button>`, preset swatch, stepper control, and slider in `TextFormatToolbar` MUST include `onMouseDown={(e) => e.preventDefault()}` and `onPointerDown={(e) => e.stopPropagation()}`.
   - This prevents the browser from shifting focus away from `contentEditable` or dropping the user's highlighted text range.
2. **Hex Input State Machine:**
   - On mount / prop change: populate local hex string from `activeFormat.fill` or `activeFormat.highlight`.
   - If `isFillMixed` is true: display placeholder `"Mixed"` and empty input value on focus so the user can immediately type without deleting text.
   - While typing (length < 6): buffer local value without calling `onApplyRangeFormat` to avoid 3-digit flashes.
   - When exactly 6 valid hex characters are entered: trigger `onApplyRangeFormat({ fill: normalized })` live.
   - On `onBlur` or `Enter`: normalize with 3-digit expansion (`#F00` -> `#FF0000`) and commit. If invalid, revert to last valid format.
3. **Eyedropper Integration:**
   - Use native `sample_screen_color` command with canvas element fallback.
   - Notify parent container via `onStartSamplingColor` so canvas backdrop does not auto-commit during pixel sampling.

## 3. TDD Test Plan (`src/features/editor/__tests__/TextFormatToolbar.test.tsx`)

Create a Vitest test suite testing component interactions and logic:

1. **Button Action Dispatches:**
   - Clicking Bold button invokes `onApplyRangeFormat({ fontWeight: 'bold' })` (or `'normal'` if already bold).
   - Clicking Italic button invokes `onApplyRangeFormat({ fontStyle: 'italic' })`.
   - Clicking Underline button invokes `onApplyRangeFormat({ textDecoration: 'underline' })`.
   - Clicking Alignment buttons invokes `onApplyBaseStyle({ align: 'center' })`.

2. **Zero-Blur Prevention:**
   - Verifies all buttons call `preventDefault()` on `mousedown` event.

3. **Hex Input Typing & Validation:**
   - Typing `FF0000` fires `onApplyRangeFormat({ fill: '#FF0000' })`.
   - Typing `1E` does not fire patch prematurely.
   - Typing `F00` and pressing `Enter` expands to `#FF0000` and fires patch.
   - Typing invalid `xyz` on blur reverts without corrupting state.

4. **Mixed State Rendering:**
   - When `isFillMixed: true`, renders mixed visual indicator on swatch and `"Mixed"` placeholder on Hex input.
   - Focusing Hex input provides clean editable input without requiring manual backspacing of `"Mixed"`.

5. **Highlight Clear Action:**
   - Clicking 1-click Clear Highlight button dispatches `onClearHighlight()`.
