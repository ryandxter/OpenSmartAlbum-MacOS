# Plan 18-03: TextInlineEditor Integration, Dual-Engine Parity & End-to-End Verification

## 1. Goal & Scope
Integrate `TextFormatToolbar` into `TextInlineEditor.tsx`, mount rich text inline editing on both Print Album Canvas and Social Carousel Canvas, enforce zero-blur focus preservation, and execute end-to-end verification across both engines:
- Docked toolbar firmly anchored to top boundary of the active text box.
- Collision avoidance: auto-flip toolbar below text box (`top: calc(100% + 8px)`) when near top viewport edge (`pos.y < 50px`).
- Focus preservation: conditional `restoreSelection` so typing into Hex `<input>` does not steal focus back to contentEditable.
- Eyedropper lock: canvas backdrop click-to-commit is disabled while sampling color.
- Undo/Redo transaction safety: intra-session `past` / `future` undo stack handles live keystrokes & formatting; pushes a single transaction to global `historyStore` upon commit.
- **Dual-Engine Parity:**
  - Create `CarouselTextNode.tsx` to render `CarouselTextFrame` with character-level `styledRanges` and `highlight` pill backgrounds on `CarouselCanvas.tsx`.
  - Mount `TextInlineEditor` on `CarouselCanvas.tsx` on text frame double-click with coordinates mapped from carousel pixel space (`1080x1080`).

## 2. Target Files & Architecture

### 2.1 `src/features/editor/TextInlineEditor.tsx` (UPDATE)
1. **Docked Toolbar Mount:**
   - Render `TextFormatToolbar` docked to the text box container.
   - Calculate viewport collision:
     ```typescript
     const isNearTop = pos.y < 50;
     const toolbarPlacementStyle: React.CSSProperties = isNearTop
       ? { position: 'absolute', top: 'calc(100% + 8px)', left: 0, zIndex: 60 }
       : { position: 'absolute', bottom: 'calc(100% + 8px)', left: 0, zIndex: 60 };
     ```
2. **Selection State & Format Binding:**
   - Track `activeFormat` in local state: computed via `getActiveSelectionFormat(draft.text, style, draft.ranges, selectionRef.current)`.
   - Update `activeFormat` on `selectionchange`, `onInput`, `onKeyUp`, and `onPointerUp`.
3. **Focus-Stealing Protection in `useLayoutEffect`:**
   ```typescript
   useLayoutEffect(() => {
     // Rebuild spans
     ...
     // Only restore DOM selection to contentEditable if contentEditable or its container is actively focused!
     const isEditorActive = document.activeElement === rootRef.current || rootRef.current?.contains(document.activeElement);
     if (isEditorActive) {
       restoreSelection(root, selectionRef.current);
     }
   }, [draft]);
   ```
4. **Eyedropper Canvas Lock:**
   - Maintain `isSamplingColor` state.
   - When sampling, backdrop `onPointerDown` ignores clicks so sampling does not dismiss the editor.
5. **Formatting Actions:**
   - `onApplyRangeFormat`: If selection is collapsed (`start === end`), applies formatting to `draft.ranges` across entire text or updates base style. If selection is active (`start < end`), applies formatting to the active slice using `applyStyleToRange`.
   - `onClearHighlight`: Calls `applyHighlightToRange(draft.ranges, selection.start, selection.end, undefined)`.

### 2.2 `src/features/carousel/CarouselTextNode.tsx` (NEW)
Konva node for rendering rich text on Social Carousel canvas:
- Uses `richTextRenderer.ts` (`layoutRichText` and `drawRichTextLayout`) to render text runs with fonts, weights, colors, and pill highlights on Konva canvas layer.
- Handles click selection and double-click to trigger inline editing.

### 2.3 `src/features/carousel/CarouselCanvas.tsx` (UPDATE)
- Include `CarouselTextNode` for all text elements in `allElements` / `slide.elements`.
- Track `editingTextId: string | null`.
- When user double-clicks a `CarouselTextFrame`:
  - Set `editingTextId = frame.id`.
  - Mount `TextInlineEditor` overlay positioned in carousel screen coordinates (`x * zoom + stagePos.x`, `y * zoom + stagePos.y`).
  - On commit: call `useCarouselStore.getState().updateTextFrame(frame.id, { text, styledRanges })`.

## 3. TDD & Automated Test Plan (`src/features/editor/__tests__/TextInlineEditorParity.test.ts`)

Create a Vitest test suite validating:

1. **Active Format Detection during Editing:**
   - Active selection of word with `#FF0000` color yields `activeFormat.fill === '#FF0000'`.
   - Active selection across `#FF0000` and `#0052B4` yields `activeFormat.isFillMixed === true`.

2. **Zero-Blur Formatting & Range Safety:**
   - Applying bold or color to range `[5, 10]` in string `"Hello World Album"` modifies only characters 5–10 without mutating outside characters 0–4 or 11–17.
   - Clearing highlight on range `[5, 10]` resets highlight without affecting text color or font weight.

3. **Intra-Session Undo vs Global History Snapshot:**
   - Intra-session edits push to local stack.
   - Commit invokes `onCommit` once with final state.

4. **Dual-Engine Text Parity:**
   - Verifies text frame update in `useAlbumStore` (Print Album) and `useCarouselStore` (Social Carousel) both accept `styledRanges` and preserve formatting identically.
