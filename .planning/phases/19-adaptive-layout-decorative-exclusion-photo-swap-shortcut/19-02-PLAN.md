## Task 4 — TDD Integration Test Suite (`PhotoSwapShortcut.test.ts`)

**Target File:** `src/features/editor/__tests__/PhotoSwapShortcut.test.ts`

Create test suite covering:
1. **Shortcut `S` with Single Selection**:
   - Pressing `S` with 1 photo frame selected sets swap handle focus state and fires toast.
   - Pressing `S` with 1 text frame or locked photo does not activate swap handle and displays warning.
2. **Shortcut `S` with Dual Selection**:
   - Pressing `S` with 2 photo frames selected calls `swapFrames` and updates store.
   - Undo restores original photo assignments.
   - Pressing `S` with 1 photo + 1 text node displays warning and does not invoke `swapFrames`.
3. **Inline Text Editing Immunity**:
   - Keydown event with target having `isContentEditable: true` or `editingTextElementId !== null` does NOT trigger swap or handle focus.
4. **Carousel Mode Parity**:
   - Pressing `S` on Carousel canvas with 2 photo frames swaps photos in `carouselStore`.
