# Plan 10-02: Carousel & Templates Panel Dynamic Integration

**Phase:** 10 - Dynamic Generative Layout Core & Non-Destructive Studio Cycling
**Plan ID:** 10-02
**Goal:** Eliminate destructive template application in Social Carousel mode; implement non-destructive `cycleSlideLayout` in `carouselStore.ts`, dynamic $N$-photo variation cards in `TemplatesPanel.tsx`, and enforce the Zero-Loss and Zero-Blank Frame invariants across all slide operations.
**Requirements:** GEN-01, GEN-02, GEN-03
**Dependencies:** Plan 10-01 (`src/domain/layout/generator.ts`)

## Context & Architectural Strategy

In the legacy implementation, `CAROUSEL_LAYOUT_PRESETS` in `carouselLayout.ts` had fixed slot counts (1, 2, 3, or 4 photos). When a slide contained 7 photos and a user clicked a 2-photo preset, 5 photos were silently dropped! Conversely, when a slide contained 1 photo and a 4-photo preset was clicked, `createFrame(photos[i])` evaluated with `photos[i] === undefined`, injecting frames with `filePath: ''` that rendered ugly blank dark-gray boxes on the canvas.

This plan integrates the pure TS generator from Plan 10-01 into `carouselStore.ts` and `TemplatesPanel.tsx`:
1. `carouselStore.ts`:
   - Track `slideLayoutIndices: Record<number, number>`
   - Add `cycleSlideLayout(direction: 'next' | 'prev')`: Generates layouts for the *exact* photo count on the slide using `generateDynamicVariations`.
   - Update `applyCarouselLayout` to enforce zero photo dropping and zero blank frame creation.
2. `TemplatesPanel.tsx`:
   - In Carousel Mode, generate dynamic layout cards for the active slide's exact photos, matching the slide's aspect ratio (1:1, 4:5, 9:16).
   - Display match scores, visual SVG previews, and layout index badges.
   - Retain multi-slide panorama presets with zero-blank safety.
3. Automated test `src/domain/__tests__/carouselGenerativeCycling.test.ts`:
   - Verifies 50 consecutive cycles on arbitrary photo counts ($N \in [1..12]$) with zero photo loss and zero empty frames.

## Tasks

### Task 1: Non-Destructive Layout Cycling in `carouselStore.ts`

<task id="10-02-T1">
**Title:** Implement `cycleSlideLayout` and Safe Preset Application in `carouselStore.ts`
**Target Files:**
- `src/stores/carouselStore.ts`

**Implementation Details:**
1. Update `CarouselState` interface:
   ```typescript
   export interface CarouselState {
     // ... existing fields ...
     slideLayoutIndices: Record<number, number>;
     cycleSlideLayout: (direction: 'next' | 'prev') => void;
     applyDynamicSlideLayoutByIndex: (slideIndex: number, variationIndex: number) => void;
   }
   ```
2. Initialize state:
   `slideLayoutIndices: {}` in store creation and reset appropriately when carousel changes.
3. Implement `cycleSlideLayout(direction: 'next' | 'prev')`:
   - Retrieve `currentCarousel` and `activeSlideIndex`. If no carousel, return.
   - Access `targetSlide = currentCarousel.slides[activeSlideIndex]`. If none, return.
   - Extract active photos:
     ```typescript
     const activeFrames = targetSlide.elements.filter(
       (el): el is CarouselPhotoFrame => el.type === 'photo' && Boolean(el.filePath)
     );
     ```
   - If `activeFrames.length === 0`, return (no photos to lay out).
   - Convert frames to `AdaptivePhoto[]`:
     ```typescript
     const photos: AdaptivePhoto[] = activeFrames.map((f) => ({
       id: f.id,
       photoId: f.photoId,
       filePath: f.filePath,
       fileName: f.fileName,
       previewPath: f.previewPath,
       thumbnailPath: f.thumbnailPath,
       photoAspect: f.photoAspect || (f.height > 0 ? f.width / f.height : 1.0),
     }));
     ```
   - Call `generateDynamicVariations`:
     ```typescript
     const variations = generateDynamicVariations(
       {
         containerWidth: currentCarousel.slideWidthPx,
         containerHeight: currentCarousel.slideHeightPx,
         spacing: 16,
         isSpread: false,
       },
       photos
     );
     ```
   - If `variations.length === 0`, return.
   - Compute `nextIndex`:
     ```typescript
     const currentIndex = get().slideLayoutIndices[activeSlideIndex] || 0;
     const nextIndex =
       direction === 'next'
         ? (currentIndex + 1) % variations.length
         : (currentIndex - 1 + variations.length) % variations.length;
     const chosen = variations[nextIndex];
     ```
   - Construct new frames:
     Map `chosen.rects` to photos using `chosen.photoAssignments`:
     ```typescript
     const newElements: CarouselPhotoFrame[] = chosen.rects.map((rect, i) => {
       const photoIdx = chosen.photoAssignments ? chosen.photoAssignments[i] : i;
       const photo = photos[photoIdx] || photos[i];
       return {
         type: 'photo',
         id: `frame-${Date.now()}-${i}-${Math.random().toString(36).slice(2, 7)}`,
         photoId: photo.photoId || photo.id,
         filePath: photo.filePath || '',
         fileName: photo.fileName,
         previewPath: photo.previewPath,
         thumbnailPath: photo.thumbnailPath,
         photoAspect: photo.photoAspect || 1.0,
         x: rect.x,
         y: rect.y,
         width: rect.width,
         height: rect.height,
       };
     });
     ```
   - Update slide:
     Replace `targetSlide.elements` with `newElements` (plus any non-photo elements such as text).
     Set `slideLayoutIndices: { ...get().slideLayoutIndices, [activeSlideIndex]: nextIndex }`.
4. Update `applyCarouselLayout`:
   - When a preset is chosen, verify that `photosToUse` has sufficient photos; if the preset defines fewer slots than photos on the slide, fall back to `generateDynamicVariations` or do not silently discard the photos.
   - Under NO circumstances allow `filePath: ''` or phantom blank frames to be added to `slide.elements`.

**Automated Verification:**
Execute test suite in Task 3 via `npx tsx src/domain/__tests__/carouselGenerativeCycling.test.ts`.
</task>

### Task 2: Dynamic Variation Cards in `TemplatesPanel.tsx`

<task id="10-02-T2">
**Title:** Replace Static Preset Iteration with Dynamic Variations in Carousel Mode
**Target Files:**
- `src/features/templates/TemplatesPanel.tsx`

**Implementation Details:**
1. In `TemplatesPanel.tsx`, inspect `activeMode`:
   - When `activeMode === 'carousel'`, read `currentCarousel`, `activeSlideIndex`, and `slideLayoutIndices`.
   - Extract `activeSlide = currentCarousel?.slides[activeSlideIndex]`.
   - Extract `carouselPhotos`:
     Filter `activeSlide.elements` for `el.type === 'photo' && Boolean(el.filePath)`.
2. Compute `carouselVariations` using `useMemo`:
   ```typescript
   const carouselVariations = useMemo(() => {
     if (!currentCarousel || !activeSlide || carouselPhotos.length === 0) return [];
     return generateDynamicVariations(
       {
         containerWidth: currentCarousel.slideWidthPx,
         containerHeight: currentCarousel.slideHeightPx,
         spacing: 16,
         isSpread: false,
       },
       carouselPhotos
     );
   }, [currentCarousel, activeSlide, carouselPhotos]);
   ```
3. Update rendering for Carousel Mode:
   - Provide sub-tabs or category toggles:
     - `Dynamic Layouts (${carouselPhotos.length} Photos)`
     - `Seamless Panoramas (Multi-Slide)`
   - Under `Dynamic Layouts`:
     - If `carouselPhotos.length === 0`:
       Render high-contrast empty state:
       "No photos on active slide. Drag photos from the filmstrip onto the slide to generate dynamic layouts."
     - If `carouselPhotos.length > 0`:
       Render list of variation cards using `AdaptiveVariationCardItem` adapted for carousel aspect ratio.
       Show:
       - Mini SVG showing exact rects.
       - Layout title and description.
       - `#index` badge and harmony score pill (`Star 92%`).
       - Clicking card calls `carouselStore.applyDynamicSlideLayoutByIndex(activeSlideIndex, idx)`.
4. Retain `Seamless Panoramas` tab for 2-slide and 3-slide panoramic templates, ensuring they also guard against blank frames.
