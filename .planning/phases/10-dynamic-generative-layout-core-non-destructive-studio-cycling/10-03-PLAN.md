## Context & Architectural Strategy

There are two major issues in current layout cycling:
1. **Spacebar Key Conflict:**
   - In `KonvaEditorCanvas.tsx` and `CarouselCanvas.tsx`, holding `Space` activates canvas hand pan (`isSpacePressed = true`).
   - In `LayoutCycleHUD.tsx`, an independent `keydown` listener directly intercepted `e.code === 'Space'` and fired `cycleSpreadLayout` immediately on key press. As a result, whenever a photographer pressed Space to pan across a high-DPI spread, the layout unexpectedly shifted before the mouse could even move!
2. **Scattered Cycling Logic:**
   - Print mode cycled spreads via `albumStore.cycleSpreadLayout`, while Carousel mode had no non-destructive cycling.
   - `cycleSpreadLayout` in `albumStore.ts` must be connected to the new `generateDynamicVariations` facade from Plan 10-01 to guarantee the Zero-Loss and Zero-Blank invariants for Print albums as well.

This plan resolves both problems:
- `LayoutCycleHUD.tsx`: Remove the conflicting `Space` keydown listener (keeping HUD buttons, tooltips, and the 'S' shuffle shortcut).
- `WorkspaceLayout.tsx`: Implement the authoritative Spacebar disambiguation state machine cleanly separating single-tap `Space` / `Shift+Space` (cycle next/prev layout) from `Space + Drag` (canvas hand pan).
- `editorStore.ts`: Add a unified `cycleLayout(direction: 'next' | 'prev')` action that routes seamlessly to either Print Album or Carousel mode.
- `albumStore.ts`: Refactor `cycleSpreadLayout` to use `generateDynamicVariations` from `src/domain/layout/generator.ts`.
- `spaceDisambiguation.test.ts`: Automated test verifying the state machine logic under various timing and drag conditions.

```
                  Spacebar Keydown Event
                            │
               ┌────────────┴────────────┐
               │  Inside input / text?   │───► YES ──► Ignore (Default Text Entry)
               └────────────┬────────────┘
                            │ NO
               ┌────────────▼────────────┐
               │ Prevent Default Scroll  │
               │ Record spaceDownTime    │
               │ Set isSpaceHeld = true  │
               └────────────┬────────────┘
                            │
              Pointer Events while Space Held
                            │
               ┌────────────┴────────────┐
               │ Mouse Drag > 3px with   │───► YES ──► Set hasDragged = true
               │ button pressed?         │             (Hand Pan Mode Active)
               └────────────┬────────────┘
                            │
                   Spacebar Keyup Event
                            │
               ┌────────────┴────────────┐
               │  !hasDragged &&         │
               │  elapsed < 600ms?       │
               └────────────┬────────────┘
                            │
             ┌──────────────┴──────────────┐
             │ YES                         │ NO
             ▼                             ▼
    [ CLEAN SINGLE TAP ]          [ PAN OR LONG HOLD ]
  Trigger cycleLayout()           No layout mutation
  (Next or Prev if Shift)
```

### Task 3: Authoritative Spacebar Disambiguation State Machine in `WorkspaceLayout.tsx`

<task id="10-03-T3">
**Title:** Implement Space Single-Tap vs Pan-Drag Disambiguation
**Target Files:**
- `src/features/workspace/WorkspaceLayout.tsx`

**Implementation Details:**
1. In `WorkspaceLayout.tsx`, declare tracking refs:
   ```typescript
   const spaceDownTimeRef = useRef<number | null>(null);
   const isSpaceHeldRef = useRef(false);
   const hasDraggedRef = useRef(false);
   const shiftHeldRef = useRef(false);
   const pointerDownPosRef = useRef<{ x: number; y: number } | null>(null);
   ```
2. Implement global keyboard and pointer event listeners:
   - **`handleKeyDown`:**
     ```typescript
     if (e.code === 'Space') {
       const target = e.target as HTMLElement;
       if (target && (target.tagName === 'INPUT' || target.tagName === 'TEXTAREA' || target.isContentEditable)) {
         return;
       }
       if (editingCropFrameId || editingTextElementId) return;

       e.preventDefault(); // Prevent page scroll
       if (e.repeat) return;

       spaceDownTimeRef.current = performance.now();
       isSpaceHeldRef.current = true;
       hasDraggedRef.current = false;
       shiftHeldRef.current = e.shiftKey;
     }
     ```
   - **`handlePointerMove` / `handleMouseMove`:**
     ```typescript
     if (isSpaceHeldRef.current && (e.buttons === 1 || e.buttons === 4)) {
       if (!pointerDownPosRef.current) {
         pointerDownPosRef.current = { x: e.clientX, y: e.clientY };
       } else {
         const dx = e.clientX - pointerDownPosRef.current.x;
         const dy = e.clientY - pointerDownPosRef.current.y;
         if (Math.hypot(dx, dy) > 4) {
           hasDraggedRef.current = true;
         }
       }
     }
     ```
   - **`handleKeyUp`:**
     ```typescript
     if (e.code === 'Space') {
       const target = e.target as HTMLElement;
       if (target && (target.tagName === 'INPUT' || target.tagName === 'TEXTAREA' || target.isContentEditable)) {
         return;
       }

       if (isSpaceHeldRef.current) {
         const downTime = spaceDownTimeRef.current;
         const elapsed = downTime !== null ? performance.now() - downTime : 9999;
         const wasDrag = hasDraggedRef.current;
         const shiftHeld = shiftHeldRef.current;

         // Reset refs
         isSpaceHeldRef.current = false;
         spaceDownTimeRef.current = null;
         hasDraggedRef.current = false;
         pointerDownPosRef.current = null;

         // Disambiguation: single tap without dragging under 600ms
         if (!wasDrag && elapsed < 600) {
           e.preventDefault();
           useEditorStore.getState().cycleLayout(shiftHeld ? 'prev' : 'next');
         }
       }
     }
     ```
3. Ensure listeners are attached to `window` with appropriate cleanup on unmount.
