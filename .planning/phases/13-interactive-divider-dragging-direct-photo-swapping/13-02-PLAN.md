## Context & Strategy
Now that `dividerGraph.ts` and store batch actions exist from Plan 13-01, Plan 13-02 implements the visual presentation and tactile interaction in:
1. `KonvaEditorCanvas.tsx` (Print Album Mode)
2. `CarouselCanvas.tsx` (Social Carousel Mode)

### Core Invariants & Architecture
1. **Zero React State Updates During Drag (DIV-02):**
   - Drag moves are intercepted at Konva node level.
   - Delta updates are applied imperatively to adjacent Konva.Group nodes (`node.width()`, `node.x()`, `node.y()`, `node.height()`) and their inner image elements via `calculateImageOffset`.
   - Redraws are scheduled via `requestAnimationFrame` coalescing on Konva layers (`layer.batchDraw()`).
2. **Hardware-Level Clamping (DIV-03):**
   - Handled via Konva's `dragBoundFunc`, keeping the divider strictly within `[minCoord * scaleFactor, maxCoord * scaleFactor]`.
3. **Single-Step Undo on Drop (DIV-05):**
   - On `dragend`, final physical dimensions are calculated from cumulative delta and committed in a single atomic transaction (`editorStore.batchUpdateFrames` or `carouselStore.batchUpdateFrames`).
4. **Direct Photo Drag Swapping & Cyan Target Ring (DIV-04):**
   - Photo frames have `draggable={!frame.locked}`.
   - During drag move, compute dragged node center point $(x_c, y_c)$ and detect if it hovers another frame.
   - Render glowing cyan target ring (`#38BDF8`, `shadowBlur: 12`, "Swap Photo" pill badge) over the target frame.
   - On drop over a target frame, reset dragged node position, execute `swapFrames(sourceId, targetId)`, and show toast.

## Tasks

<task id="13-02-01">
### Task 1: Create `src/features/editor/DividerOverlayLayer.tsx`
Create reusable Konva component `DividerOverlayLayer`:
- Computes `CanvasDivider[]` from active frames using `extractCanvasDividers`.
- For each divider:
  - Invisible wide hit area (16px width/height) with cursor `col-resize` or `row-resize`.
  - On hover: reveals sleek `#38BDF8` accent line (2px width, rounded ends).
  - Draggable with `dragBoundFunc` enforcing `minCoord` / `maxCoord` and locking orthogonal axis.
  - Imperative drag loop: updates adjacent Konva node dimensions directly, recalcs image offsets, schedules `layer.batchDraw()` via RAF.
  - On `dragend`: commits final geometries via `onCommit(updates)`.
</task>

<task id="13-02-02">
### Task 2: Mount Divider Dragging & Direct Photo Swapping in `KonvaEditorCanvas.tsx`
- Mount `DividerOverlayLayer` on `InteractionOverlayLayer` (Layer 4).
- Add direct photo drag swapping to photo frames:
  - During `onDragMove`: check if frame center is inside another frame using `findPhotoSwapTarget`. If so, set `hoveredSwapTargetFrameId`.
  - In Layer 4, render the glowing cyan target ring and "Swap Photo" pill badge when `hoveredSwapTargetFrameId` is active.
  - On `onDragEnd`: if `hoveredSwapTargetFrameId` is set, snap node back to origin and dispatch `useEditorStore.getState().swapFrames(spread.id, frame.id, hoveredSwapTargetFrameId)`.
</task>

<task id="13-02-03">
### Task 3: Mount Divider Dragging & Direct Photo Swapping in `CarouselCanvas.tsx`
- Mount `DividerOverlayLayer` (configured for pixel dimensions and carousel scale).
- Support direct photo drag swapping between frames on the carousel canvas with the same cyan target ring and `useCarouselStore.getState().swapFrames`.
</task>
