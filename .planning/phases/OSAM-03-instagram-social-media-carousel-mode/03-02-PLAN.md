### Task 1: Create CarouselCanvas Component

**File**: `src/features/carousel/CarouselCanvas.tsx` (NEW)
**CSS**: `src/features/carousel/CarouselCanvas.module.css` (NEW)

The carousel canvas renders all slides as a single continuous Konva Stage. Total stage width = N × slideWidthPx.

**Core Architecture:**

```typescript

  onToast?: (msg: string) => void;
}

export function CarouselCanvas({ zoomLevel, fitTrigger, onZoomChange, onToast }: CarouselCanvasProps) {
  // ... canvas setup matching KonvaEditorCanvas pattern
}
```

**Key sub-components:**

1. **`CarouselPhotoFrameNode`** — renders a `CarouselPhotoFrame` using the same preview-path-first asset hierarchy as `PhotoFrameNode` in KonvaEditorCanvas.

2. **`SliceBoundaryGuide`** — for each boundary at x = slideIndex * slideWidthPx:
   - Dashed vertical line (`Line` with `dash={[8, 6]}`, stroke `rgba(255,255,255,0.4)`)
   - Numbered badge at top: `Rect` fill `rgba(0,0,0,0.6)` + `KonvaText` "Slide 1", "Slide 2", ...
   - Rendered in a non-interactive overlay `Layer` (`listening={false}`)
   - Only shown when `showSliceGuides` state is `true`

3. **Stage setup** — use the same `calculatePasteboardViewport` + `preservePasteboardView` from `src/domain/viewport.ts`:

```typescript
const totalWidth = currentCarousel ? getCarouselTotalWidth(currentCarousel) : 1080;
const totalHeight = currentCarousel?.slideHeightPx ?? 1080;
const scaleFactor = Math.min(
  availableWidth / totalWidth,
  availableHeight / totalHeight
) * (zoomLevel / 100);
```

4. **Trackpad pinch-to-zoom** — reuse same `Math.exp(-deltaY * 0.006)` pattern from `KonvaEditorCanvas`

5. **Active slide highlight** — on the background layer, render a thin `Rect` border `rgba(255, 255, 255, 0.15)` around the active slide region

**Seamless photo spanning**: Photos with x coordinates that cross a slide boundary (e.g., a frame at x=800, width=500 in a 1080px slide) simply render at their full position on the continuous stage — no special handling needed. The slice guides are decorative overlays, not actual masking.

### Task 3: Create Phone Swipe Simulator Modal

**File**: `src/features/carousel/PhoneSwipeSimulator.tsx` (NEW)
**CSS**: `src/features/carousel/PhoneSwipeSimulator.module.css` (NEW)

A full-screen modal overlay with:
- Centered iPhone-style frame bezel (390×844 viewport, no actual image needed — CSS border-radius + box-shadow mimics iPhone)
- Inside the frame: horizontally scrollable content using CSS scroll-snap
- Each slide rendered as an IMG element pointing to slide thumbnail (fallback: slide background color)
- Navigation arrows Left/Right to step through slides
- Slide indicator dots at bottom
- Keyboard: `←`/`→` arrows navigate, `Escape` closes

**Implementation approach** — CSS scroll-snap based (no animation library):

```css
.slidesTrack {
  display: flex;
  scroll-snap-type: x mandatory;
  overflow-x: scroll;
  scroll-behavior: smooth;
  scrollbar-width: none;
  width: 100%;
  height: 100%;
}
.slide {
  flex: 0 0 100%;
  scroll-snap-align: start;
}
```

Navigate programmatically via `scrollTo({ left: slideIndex * phoneWidth, behavior: 'smooth' })`.

**Props:**
```typescript
interface PhoneSwipeSimulatorProps {
  isOpen: boolean;
  onClose: () => void;
}
```
