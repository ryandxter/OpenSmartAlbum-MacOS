# Plan 11-02: Multi-Spread Auto-Flow UI & Store Integration

**Phase:** 11 - Auto-Flow Multi-Spread Storytelling Engine
**Plan ID:** 11-02
**Goal:** Integrate the auto-flow engine into `albumStore.ts`, `carouselStore.ts`, and `WorkspaceLayout.tsx` for external drops and filmstrip tray actions, with atomic history transactions and non-blocking asynchronous execution.
**Requirements:** FLOW-01, FLOW-04, FLOW-05
**Dependencies:** Plan 11-01 (`src/domain/storytelling/autoFlowEngine.ts`)

---

## Tasks

### Task 1: Store Multi-Spread Auto-Flow Actions
<task id="11-02-T1">
**Title:** Implement `autoFlowAlbumSpreads` in `albumStore.ts` and `autoFlowCarouselSlides` in `carouselStore.ts`
**Target Files:**
- `src/stores/albumStore.ts`
- `src/stores/carouselStore.ts`

**Details:**
1. In `src/stores/albumStore.ts`:
   - Add `autoFlowPhotosToSpreads: (photos: Photo[], project: Project, options?: { replaceCurrentSpread?: boolean }) => Promise<void>;`
   - Atomically push snapshot to `useHistoryStore.getState().pushState(currentAlbum)`.
   - Calculate `AutoFlowSpreadPlan[]` using `generateAutoFlowPlan`.
   - If `replaceCurrentSpread` and active spread is empty, populate active spread with first plan, and append remaining spreads sequentially.
   - For each plan, convert plan's variation and photos into `PhotoFrameElement[]` via `buildSpreadElementsFromVariation`.
   - Update album spreads and recalculate page numbers.
   - Set active spread to the newly created spread and mark `saveStatus: 'unsaved'`.
2. In `src/stores/carouselStore.ts`:
   - Add `autoFlowPhotosToSlides: (photos: Photo[]) => Promise<void>;`
   - Calculate plans using single-slide dimensions ($1080 \times 1080$ or active ratio).
   - Append slides and populate frames with zero photo loss and zero blank frames.
</task>

### Task 2: Canvas Finder Drop Auto-Flow Integration
<task id="11-02-T2">
**Title:** Route Multi-Photo Drops ($>6$ photos) to Auto-Flow Pipeline in `WorkspaceLayout.tsx`
**Target Files:**
- `src/features/workspace/WorkspaceLayout.tsx`

**Details:**
1. In `WorkspaceLayout.tsx` (`handleCanvasFinderDrop`):
   - When dropped photo count $> 6$:
     - Show toast: `Auto-flowing ${newPhotos.length} photos across sequential spreads...`
     - In Print Mode: call `autoFlowPhotosToSpreads(newPhotos, currentProject, { replaceCurrentSpread: activeSpreadIsEmpty })`.
     - In Carousel Mode: call `autoFlowPhotosToSlides(newPhotos)`.
   - Wrap in atomic transaction so a single `Cmd+Z` reverts the entire drop.
</task>

### Task 3: Filmstrip Tray "Auto-Flow" Action Button
<task id="11-02-T3">
**Title:** Add "Auto-Flow Selected Photos" Action in `FilmstripTray.tsx`
**Target Files:**
- `src/features/photos/FilmstripTray.tsx`

**Details:**
1. When photos are selected in FilmstripTray:
   - If selected count $\ge 2$:
     - Display an "Auto-Flow (N)" button in the tray toolbar with a Sparkles icon.
     - Clicking calls `autoFlowPhotosToSpreads` (Print mode) or `autoFlowPhotosToSlides` (Carousel mode).
     - Deselects photos and marks them as used.
</task>
