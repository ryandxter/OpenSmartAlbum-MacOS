# Plan 05-01: Pure Rust Layered PSD Serializer & Instagram Carousel Slice Exporter

**Phase**: OSAM-05-advanced-layered-export-suite  
**Plan**: 05-01  
**Requirements**: EXPO-01, EXPO-02  
**Status**: Ready to Execute  
**Date**: 2026-09-22  

---

## 1. Objective

Implement a high-performance, 100% pure Rust layered Adobe Photoshop (`.psd`) document serializer and an automated Instagram Carousel multi-slide slice exporter. 

1. **EXPO-01 (Layered PSD Serializer)**: Produces valid 5-section Adobe Photoshop files featuring discrete photo raster layers with exact pixel bounds `(top, left, bottom, right)`, non-destructive grayscale channel layer masks (`id = -2`) for non-rectangular shape clipping presets (circle, rounded rect, hexagon, scallop, heart, custom SVG), PackBits RLE channel compression, 300 DPI `ResolutionInfo` metadata (`0x03ED`), and a merged composite RGB section.
2. **EXPO-02 (Instagram Carousel Multi-Slide Slicer)**: Renders digital pixel-based multi-slide layouts into continuous panoramic canvases, slicing them seamlessly into individual high-resolution numbered slide images (`slide_01.jpg`, `slide_02.jpg`, ... `slide_N.jpg`) and a full stitched preview (`full_panorama.jpg`) inside a timestamped output directory `[ProjectName]_Carousel_[Timestamp]/`.

---

## 2. Context & Technical Specifications

- **Offline & Pure Rust**: Eliminates heavy external C libraries (`libvips`, `ImageMagick`) and avoids unverified crates with Rust Edition 2024 incompatibilities (e.g. `ag-psd`). Implemented with pure Rust standard I/O and `image` crate buffers.
- **PSD Big-Endian Specification**:
  - **Header (26 bytes)**: Signature `8BPS`, Version `1`, 3 Channels, Height, Width, Depth `8`, ColorMode `3` (RGB).
  - **Color Mode Data (4 bytes)**: Length `0`.
  - **Image Resources**: `8BIM` block `0x03ED` (`ResolutionInfo`) embedding project DPI (e.g., $300\text{ DPI} \ll 16 = 0x012C0000$).
  - **Layer & Mask Info**: Layer count, layer records (bounds, channels 0=R, 1=G, 2=B, -1=Alpha, -2=Mask, blend mode `norm`, opacity 255, 4-byte padded Pascal string names), and channel data with PackBits RLE compression.
  - **Merged Composite**: Planar R, G, B channels with PackBits compression.
- **Instagram Carousel Geometry**:
  - Slides: $1080 \times 1080$ (1:1), $1080 \times 1350$ (4:5), or $1080 \times 1920$ (9:16).
  - Stage: continuous width $W_{total} = N \times \text{slideWidthPx}$. Photos spanning across slide boundaries render seamlessly without border seam artifacts.

## 3. Tasks

### Task 1: Pure Rust Layered PSD Encoder (`src-tauri/src/export_engine/psd_writer.rs`)
- **File**: `src-tauri/src/export_engine/psd_writer.rs`
- **Responsibilities**:
  1. **PackBits RLE Compression**:
     - Implement Apple/Adobe PackBits algorithm:
       - Literal runs ($1 \dots 128$ bytes): `(n - 1) as i8` followed by $n$ literal bytes.
       - Replicate runs ($2 \dots 128$ identical bytes): `-(n - 1) as i8` followed by byte value.
     - Provide row-by-row compressor calculating 2-byte row lengths (`u16` BE).
  2. **Shape Mask Generation (`id = -2`)**:
     - For non-rectangular elements (`shapeType` present or `cornerRadius > 0`):
       - Allocate grayscale mask buffer of size `(w, h)`.
       - Render anti-aliased shape opacity (inside = `255`, border = anti-aliased, outside = `0`).
       - Attach as Channel ID `-2` with Layer Mask Info record (mask top, left, bottom, right matching frame bounds, default color 0).
  3. **Layer Record Builder**:
     - Layer struct:
       ```rust
       pub struct PsdLayer {
           pub name: String,
           pub top: i32,
           pub left: i32,
           pub bottom: i32,
           pub right: i32,
           pub image: RgbaImage,
           pub mask: Option<ImageBuffer<image::Luma<u8>, Vec<u8>>>,
       }
       ```
     - Pascal string name padding: ensure length byte + string bytes are padded with `0x00` to an integer multiple of 4 bytes.
  4. **5-Section Binary Serializer**:
     - Implement `write_psd_file(path: &Path, width: u32, height: u32, dpi: u32, layers: &[PsdLayer], composite: &RgbaImage) -> Result<(), String>`.
     - Write Header, Color Mode Data, 0x03ED ResolutionInfo resource, Layer & Mask section, and Composite RLE planar RGB image.

### Task 2: Multi-Slide Carousel Slicer (`src-tauri/src/export_engine/carousel_slicer.rs`)
- **File**: `src-tauri/src/export_engine/carousel_slicer.rs`
- **Responsibilities**:
  1. **Data Payloads**:
     - Define Serde payloads matching frontend `Carousel`:
       ```rust
       #[derive(Debug, Clone, Serialize, Deserialize)]
       #[serde(rename_all = "camelCase")]
       pub struct CarouselPayload {
           pub project_id: String,
           pub project_name: String,
           pub ratio: String,
           pub slide_width_px: u32,
           pub slide_height_px: u32,
           pub total_slides: usize,
           pub slides: Vec<CarouselSlidePayload>,
       }

       #[derive(Debug, Clone, Serialize, Deserialize)]
       #[serde(rename_all = "camelCase")]
       pub struct CarouselSlidePayload {
           pub id: String,
           pub slide_index: usize,
           pub background_color: String,
           pub elements: Vec<CarouselElementPayload>,
       }

       #[derive(Debug, Clone, Serialize, Deserialize)]
       #[serde(rename_all = "camelCase")]
       pub struct CarouselElementPayload {
           pub id: String,
           pub file_path: Option<String>,
           pub preview_path: Option<String>,
           pub x: f64,
           pub y: f64,
           pub width: f64,
           pub height: f64,
           pub crop_x: Option<f64>,
           pub crop_y: Option<f64>,
           pub crop_scale: Option<f64>,
           pub rotation: Option<f64>,
           pub corner_radius: Option<f64>,
           pub shape_type: Option<String>,
       }

       #[derive(Debug, Clone, Serialize, Deserialize)]
       #[serde(rename_all = "camelCase")]
       pub struct CarouselExportOptions {
           pub output_dir: String,
           pub jpeg_quality: u8,
           pub export_panorama: bool,
           pub file_prefix: Option<String>,
       }

       #[derive(Debug, Clone, Serialize, Deserialize)]
       #[serde(rename_all = "camelCase")]
       pub struct CarouselExportResult {
           pub output_folder: String,
           pub slide_files: Vec<String>,
           pub panorama_file: Option<String>,
           pub total_slides: usize,
       }
       ```
  2. **Continuous Panoramic Stage Rendering**:
     - Allocate stage buffer: $W_{total} = \text{total\_slides} \times \text{slide\_width\_px}$, $H = \text{slide\_height\_px}$.
     - Fill background colors per slide partition $[i \times W_{slide} \dots (i+1) \times W_{slide}]$.
     - Composite photo elements at continuous coordinates $(x, y, w, h)$.
  3. **Slide Slicing & Storage**:
     - Create output directory: `[ProjectName]_Carousel_[YYYYMMDD_HHMMSS]/` within `options.output_dir`.
     - For $i = 0 \dots N-1$:
       - Crop slice $[i \times W_{slide} \dots (i+1) \times W_{slide}, 0 \dots H_{slide}]$.
       - Save to `slide_01.jpg`, `slide_02.jpg`, etc. with `encode_jpeg_with_dpi` (quality = 92-95, DPI = 72).
     - If `export_panorama` is true, save full continuous canvas to `full_panorama.jpg`.
