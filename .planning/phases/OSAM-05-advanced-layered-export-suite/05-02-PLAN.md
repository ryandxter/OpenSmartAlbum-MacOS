## 1. Objective

Complete the advanced export suite by adding professional prepress archival formats (lossless TIFF and print-ready PDF/X with vector marks) and delivering an intuitive, unified 5-format export UI dialog in the frontend supporting both print albums and Instagram carousel publishing.

1. **EXPO-03 (Lossless Prepress TIFF)**: Implement an LZW-compressed 8-bit and 16-bit RGB TIFF encoder with embedded prepress resolution tags (`ResolutionUnit = 2 (Inch)`, `XResolution = 300/1`, `YResolution = 300/1`), preventing generation loss for professional print laboratories.
2. **EXPO-04 (Print-Ready PDF/X with Vector Marks)**: Implement multi-page prepress PDF/X documents featuring explicit box hierarchies (`MediaBox`, `BleedBox`, `TrimBox`), vector hairline corner trim marks, center spine fold ticks, slug text info, and standard PDF/X-3 output intent metadata.
3. **Unified Frontend Suite (`ExportAlbumDialog.tsx`)**: Elevate the export modal with 5 distinct format cards (JPEG, PNG, TIFF, PDF/X, PSD), context-adaptive configuration panels, and Instagram Carousel Slice export integration.

---

## 2. Context & Architecture

- **TIFF Integration**: Rust's `image` crate utilizes `tiff` under the hood. Adding direct dependency `tiff = { version = "0.11", default-features = false, features = ["lzw", "deflate"] }` to `src-tauri/Cargo.toml` grants full control over rational resolution metadata and 16-bit deep-color plane serialization.
- **PDF Prepress Box Hierarchy**:
  - `TrimBox`: Finished page dimensions after cutting (e.g. $[200 \times 200]\text{ mm}$).
  - `BleedBox`: TrimBox + outer bleed margins (e.g. $+3\text{ mm}$ on each trim boundary).
  - `MediaBox`: BleedBox + slug margin area (e.g. $+5\text{ mm}$ slug on all sides) housing vector crop marks and project metadata labels.
- **Vector Marks Stream**: Emits clean PDF operator commands (`0.5 w`, `0 0 0 RG`, `m`, `l`, `S`) directly into the page content stream to ensure infinite vector resolution on commercial platesetters (Kodak Prinergy, Heidelberg Suprasetter).

### Task 2: Print-Ready PDF/X with Bleed & Vector Marks (`src-tauri/src/export_engine/mod.rs`)
- **File**: `src-tauri/src/export_engine/mod.rs`
- **Responsibilities**:
  1. Extend `ExportOptions`:
     ```rust
     #[serde(default)]
     pub pdf_print_ready: bool,
     #[serde(default = "default_slug_mm")]
     pub slug_mm: f64, // e.g. 5.0 mm
     #[serde(default = "default_true")]
     pub crop_marks: bool,
     ```
  2. Enhance `assemble_pdf_from_jpegs` to support print-ready PDF/X mode:
     - Calculate point dimensions:
       - Trim dimensions: `(w_pt, h_pt)`
       - Slug margin: `slug_pt = (options.slug_mm / 25.4) * 72.0`
       - Bleed margin: `bleed_pt = (bleed_mm / 25.4) * 72.0`
       - Total MediaBox: `[0 0 (w_pt + 2 * slug_pt) (h_pt + 2 * slug_pt)]`
       - BleedBox: `[(slug_pt - bleed_pt) (slug_pt - bleed_pt) (slug_pt + w_pt + bleed_pt) (slug_pt + h_pt + bleed_pt)]`
       - TrimBox: `[slug_pt slug_pt (slug_pt + w_pt) (slug_pt + h_pt)]`
  3. Emit Vector Marks in Content Stream:
     - 8 Corner Trim Marks: hairline width `0.5 w`, registration color `0 0 0 RG`, offset $2\text{ mm}$ outside TrimBox, length $4\text{ mm}$.
     - Center Spine Fold Ticks: vertical ticks on top and bottom slug margins at `x = slug_pt + w_pt / 2.0`.
     - Slug Metadata Text: `BT /F1 8 Tf slug_x slug_y Td (Project: ... | Spread: ... | DPI: 300) Tj ET`.
  4. PDF/X Output Intent & GTS Tags:
     - Add `/OutputIntents [ << /Type /OutputIntent /S /GTS_PDFX /OutputConditionIdentifier (sRGB IEC61966-2.1) ... >> ]` to `/Catalog`.
     - Add `/GTS_PDFXVersion (PDF/X-3:2002)` to `/Info` dictionary.
